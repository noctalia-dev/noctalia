# Nythera Files: Places and file interaction

The standalone native file manager owns these interactions in `src/filemanager/file_manager.*`, with discovery and device operations in `places_model.*` and file transfers in `file_operation_manager.*`.

- The sidebar divider uses a surface-local logical-coordinate delta from the original press. Wayland's implicit button grab retains the gesture until release; Escape cancels it. Hover/drag use the horizontal resize cursor and a palette-aware highlight. Width persists in the existing `files` state table.
- Personal locations come from GLib's configured XDG directories. Valid directory symlinks are accepted; canonical targets are deduplicated. Missing or broken locations are omitted without creating anything. Categories configured as Home are deduplicated against Home, even if separate conventional symlinks exist.
- Wastebin browses the GIO `trash:///` namespace, including child folders. Internal history tokens are explicitly routed to GIO URIs and never passed to local file operations. Original locations appear in tooltips where the backend supplies them. Refresh is explicit; Restore and Empty Wastebin are not implemented.
- Folder and directory-background menus can add local folders to Places, with a chosen display name. Saved entries use independent UUIDs and retain their chosen absolute paths (including valid symlinks); their names, identities and order persist together through the existing TOML state store and atomic writer. Removing an entry does not remove the folder. All rows can be reordered within their existing Personal, Devices or Network group; insertion lines indicate positions. Built-ins and pinned folders share one Personal sequence. The separate `place_order` identity list retains disconnected resources and persists through the existing state store. Initial Devices and Network discovery is alphabetical by human-readable label; newly discovered unsorted resources follow the saved sequence alphabetically. GIO volume UUID identities remain stable across mount/unmount and mount-path changes. Dragging local folders into Personal insertion strips pins them without transferring files; the centre of folder rows remains an ordinary transfer target. Duplicate canonical folder targets are rejected while bookmark paths retain valid symlink spelling.
- NFS, SMB and SSHFS use Network. Other local FUSE mounts, including rclone, use Devices. Mounted and unmounted devices share the user-defined order. Unmounted volume status is secondary text beneath its name, without a capacity bar.
- Device menus expose only GIO-supported mount, unmount and eject operations. Async requests retain their GIO objects independently of scene rows and use matching finish methods. Native GMountOperation prompts collect credentials in memory, never save passwords, and use the existing session authentication agent where GIO delegates authentication. Busy requests never force removal or kill processes. Transfers block removal of any source/destination mount until their workers actually finish, including after cancellation. Eject conservatively waits for all transfers because it may affect sibling volumes. Device requests block new file operations until completion.
- Internal pointer drags preserve selected files and folders and accept folder, saved-Place and mounted-device destinations. They use the existing staged transfer manager, conflict dialogs, cancellation and notifications. Self and recursive drops are rejected, including aliases through symlinks. The default is move on the same filesystem and copy across filesystems; Ctrl copies and Shift moves. Escape cancels the drag. Cross-application Wayland DnD is absent.
- Ctrl+vertical wheel over the file view adjusts its persistent scale from 80% to 180%. List rows start at 32 logical pixels with a one-pixel gap; grid cells use 106-pixel height. Fonts, icons and geometry scale together. Normal scrolling and sidebar/UI scale are unchanged; inline rename defers zoom.

Focused fixture tests cover configured XDG symlinks and deduplication, discovery signal routing, unsupported device operations, drop-target safety, all-source transfer mount tracking, and cancellation completion timing. These tests do not prove real-device lifecycle or native visual/input correctness; record live verification separately when changing these interactions. Use disposable fixtures and removable test media for operation tests.

## UI correctness pass — 15 November 2026

Personal entries now supply standard themed icon names through `FileIcon` and `IconResolver`, including configured XDG categories and saved folders. Places use a consistent 22-logical-pixel icon box; Wastebin prefers regular themed artwork with a symbolic and native-glyph fallback. Symbolic artwork follows the foreground colour. Theme reload advances the artwork generation even when the theme name stays the same. XDG discovery and Home deduplication are unchanged.

Root and Home filesystem entries retain meaningful GIO volume or mount names. Where GIO omits the host volume, the Unix-mount fallback matches its device against existing udev `/dev/disk/by-label` aliases and decodes their escaped labels. It does not probe disks or add a direct UDisks2 dependency. User-named mounts, Btrfs filtering, capacities and navigation retain their existing paths.

File artwork queries GIO's no-follow symlink flag, then follows the explicitly displayed link to obtain target artwork. `FileIcon` overlays the configured theme's symbolic-link emblem, or an unreadable emblem for a broken link, with native glyph fallbacks. Broken links never fall back to folder artwork. This lookup does not change discovery or file-operation follow policies. List icon boxes are 22 times the view scale; grid icon boxes occupy 85% of the existing preview's smaller dimension. At 80%, 100% and 180%, list boxes are 17.6, 22 and 39.6 logical pixels, and grid boxes are approximately 40.9, 51.1 and 91.9 logical pixels. Artwork requests include the output render scale, while images retain their aspect ratio.

Places content stretches its groups so the selection, hover and hit surfaces include icons, text and normal row padding. Navigation rows use explicit selection rather than retaining a focus-derived hover. Shared Buttons refresh their visual state when a press is cancelled. The virtual grid rebinds pooled items after their dimensions change; previously the outer hit cells resized while inner rows and backgrounds could retain their old geometry until hovered. Gutter boundaries are excluded from hits, and fractional list row heights match their cells.

Breadcrumb construction normalises filesystem and Wastebin paths, excludes trailing empty components and the URI scheme, and selects the final constructed destination instead of comparing a separator-sensitive path. The previous path comparisons could leave a trailing-separator location without a current highlight. The reported extra narrow highlighted Wastebin segment was not reproduced either before or after this pass; its exact cause remains unverified. The existing clipped bar and editable address mode are retained.

Validation: both `nythera` and `nythera-file-manager` built incrementally with two jobs. Ten focused tests passed: `button_layout`, `icon_resolver`, `input_dispatcher`, `state_store`, `virtual_grid_view_gesture`, `context_menu_popup`, `file_interaction`, `places_model`, `gio_poll_source` and `file_operation_manager`. Added regressions cover virtual and trailing-separator breadcrumbs, XDG icon names, valid directory/file/outside links and broken links, target artwork, udev label decoding, stretched row hits, press cancellation, cell resize rebinding and gutter boundaries.

Native verification used an unlocked Umbriel session, disposable fixtures and isolated state containing a copy of the existing theme settings. Captures were inspected for list and grid at minimum/default/maximum zoom, symlink emblems, Places icons, the live `CachyOS` root label, and root/Home/nested/Wastebin transitions. A narrow window was also inspected. Ctrl+wheel changed the saved scale; the minimum scale survived an application restart. Wheel scrolling without Ctrl moved the grid while leaving the scale at 180%. Pointer selection, full-row hover and a directory-background context menu were observed. Precise multi-selection, completed drag-and-drop, item context-menu activation isolation, real device operations and a different live icon theme were not verified in this pass. The automated gesture, operation and resolver checks are separate evidence, not native acceptance of those interactions.

## Interaction completion — 15 November 2026

Empty-space left drags now use a clipped, palette-driven selection rectangle in both views. The grid intersects logical cells rather than recycled nodes. Files owns selection baselines and Ctrl toggle/Shift range semantics; Escape restores the baseline. A gesture-scoped timer drives edge scrolling even with a stationary pointer, without changing ordinary scrolling. Navigation, model changes and zoom cancel stale gestures. Item drags remain separate from selection.

Zoom now changes artwork independently of typography and metadata columns. At minimum/default/maximum zoom, list icons measure 16/22/56 logical pixels and rows 32/32/66; grid icons measure 32/48/112 and cells reserve only fixed label space and controlled padding. IconResolver continues to request artwork at the displayed size and surface scale. Target artwork carries a palette-backed chain badge; broken links use a broken chain and error palette. GIO supplies explicit link type and lexically resolved relative target information. Selection shows a bounded Type footer; Alt+Enter opens the complete information in the existing scrollable dialog. Native tooltips are now connected for file and Places metadata. Files requires a fresh 500 ms hover after target changes or recycled-row rebinding, and suppresses tooltips during menus, pointer capture, drags and selection gestures. Input dispatch and layout revalidate hover; file and Places tooltips share a pointer-relative anchor in parent-surface logical coordinates. Places tooltips show the display name, available mount path/filesystem type and cached capacity; network/FUSE sources are retained, raw mount flags are omitted, and unmounted devices show only their name and state. The existing Wayland positioner flips/slides these popups at output edges; shell widgets retain their fast retargeting policy. Native placement and interaction acceptance require manual verification.

Internal file drags now carry a non-interactive native scene overlay with themed artwork, a filename or selection count, and copy/move/pin/invalid feedback. It follows surface-local coordinates with a pointer offset and flips inward at window edges. Drop, Escape, leave, navigation and closure clear it. Sidebar insertion strips pin folders; row centres retain transfer semantics. Drop validation checks the source directory entry without following symlinks, allowing dangling links to transfer while retaining recursive-folder guards.
