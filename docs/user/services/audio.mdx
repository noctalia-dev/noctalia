```toml
[audio]
enable_overdrive           = false  # allow volume sliders above 100% (up to 150%)
enable_sounds              = true   # master toggle for shell sounds (plugins unaffected)
enable_volume_sounds       = true   # sound on volume changes
enable_notification_sounds = true   # sound on notifications
enable_power_sounds        = true   # sound on charger connect/disconnect
enable_screenshot_sounds   = true   # sound on screenshots
sound_volume               = 0.5    # global sound volume (0.0 - 1.0)
sound_theme                = "freedesktop"
```

- `enable_overdrive = false` clamps Control Center output/microphone sliders to 100%; `true` allows up to 150%.
- `enable_sounds = false` disables all shell sound playback. Plugin sounds via `noctalia.sound.play` are not
  affected by `enable_sounds` or the per-event toggles.
- While `enable_sounds` is `true`, each per-event toggle gates one shell sound: `enable_volume_sounds` (volume
  changes), `enable_notification_sounds` (notifications), `enable_power_sounds` (charger connect or remove), and
  `enable_screenshot_sounds` (screenshots).
- `sound_volume` controls all UI sounds. A value of `1.0` plays the source at unity gain; lower values follow a
  perceptual volume curve.
  Files are decoded through `libsndfile`; common supported formats include WAV, FLAC, Ogg/Vorbis, Opus, MP3, and AIFF.
  Exact format support depends on the distribution's libsndfile build.
- `sound_theme` selects an installed sound theme. Themes inherit from their declared parents and fall back
  to `freedesktop`; shell sounds are loaded from each theme's `stereo` directory.
  Premade themes are available on [Pling](https://www.pling.me/browse?cat=316&ord=rating); install them under
  `~/.local/share/sounds/<theme-name>/`. To create your own, follow the
  [freedesktop Sound Theme Specification](https://specifications.freedesktop.org/sound-theme/0.2/).
- Shell sounds use these theme events: `message-new-instant` (notifications), `audio-volume-change` (volume
  changes), `power-plug` / `power-unplug` (laptop charger connected or removed), and `screen-capture`
  (screenshots). If a theme lacks the exact event, its trailing dash components are stripped (e.g.
  `message-new-instant`, then `message-new`, then `message`) before trying parent themes.

Noctalia reconnects automatically if the PipeWire daemon restarts or is temporarily unavailable. Audio devices and
controls disappear while the daemon is offline and repopulate after PipeWire and its session manager are ready again.
