Bars are named subtables under `[bar.*]`, configured in **Settings → Bar**. Each bar appears on every connected monitor, then per-monitor overrides apply.

```toml
# One top bar with widgets in three lanes
[bar]
order = ["default"]

[bar.default]
position = "top"
thickness = 34
start  = ["launcher", "wallpaper", "workspaces"]
center = ["clock"]
end    = ["media", "tray", "notifications", "clipboard", "network", "bluetooth", "volume", "brightness", "battery", "control-center", "session"]
```

## Bar settings

You can define several `[bar.*]` entries; each is configured independently and rendered on all monitors. Widget tooltips open on the side facing into the screen, so they don't cover other bar widgets.

```toml
[bar]
order = ["main"]

[bar.default]
position           = "top"
enabled            = true
auto_hide          = false
auto_hide_delay_ms = 0
smart_auto_hide    = false
show_on_workspace_switch = true
reserve_space      = true
auto_hide_reserve_space = false
layer              = "top"

thickness          = 34
background_opacity = 1.0
compositor_blur    = true
border             = "outline_variant"
border_width       = 0.0
shadow             = true
contact_shadow     = false
panel_overlap      = 1
radius             = 12
radius_top_left    = 12
radius_top_right   = 12
radius_bottom_left = 12
radius_bottom_right = 12
concave_edge_corners = true
margin_ends        = 100
margin_edge        = 0
margin_opposite_edge = 0
padding            = 14
widget_spacing     = 6
hover_highlight    = true
show_tooltip       = true
scale              = 1.0
font_scale         = 1.0
font_weight        = 500
font_family        = ""

capsule            = false
capsule_fill       = "surface_container"
capsule_thickness  = 0.76
capsule_radius     = 8.0           # omit for automatic pill radius
capsule_opacity    = 1.0
# capsule_border   = "outline_variant"
capsule_border_width = 1.0

start  = ["launcher", "wallpaper", "workspaces"]
center = ["clock"]
end    = ["media", "tray", "notifications", "clipboard", "network", "bluetooth", "volume", "brightness", "battery", "control-center", "session"]
```

### Placement and layering

| Setting                  | Type          | Default | Description                                                                                                                                                                                                               |
| ------------------------ | ------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `[bar].order`            | list          | `[]`    | Order in which bar surfaces are created. Matters only for bars with `reserve_space = true`; the compositor still owns the final arrangement. Unlisted names are appended.                                                 |
| `position`               | string        | `top`   | `top`, `bottom`, `left` or `right`.                                                                                                                                                                                       |
| `enabled`                | bool          | `true`  | Show or hide this bar.                                                                                                                                                                                                    |
| `layer`                  | string        | `top`   | `top`, `overlay` (above fullscreen apps) or `auto`. See [Auto-hide](#auto-hide) for `auto`.                                                                                                                               |
| `reserve_space`          | bool          | `true`  | Reserve a compositor exclusive zone so windows are pushed away. See [Auto-hide](#auto-hide).                                                                                                                              |
| `margin_ends`            | int or string | `100`   | Inset from each end along the main axis: logical pixels (`100`) or a percentage of the screen length (`"15%"`, 0 to 49). A percentage is computed per monitor.                                                            |
| `margin_edge`            | int           | `0`     | Distance from the nearest screen edge. Positive values float the bar.                                                                                                                                                     |
| `margin_opposite_edge`   | int           | `0`     | Extra reserved space on the inward side of the bar. The bar doesn't move; windows stop further away. Use it when a compositor under-reserves (for example labwc with maximized windows). Requires `reserve_space = true`. |
| `padding`                | int           | `14`    | Main-axis padding from the bar ends to the start and end sections.                                                                                                                                                        |
| `widget_spacing`         | int           | `6`     | Gap between widgets within a section.                                                                                                                                                                                     |
| `start`, `center`, `end` | list          |         | Widgets in each lane.                                                                                                                                                                                                     |

### Text and scale

| Setting       | Type   | Default | Description                                                                                                                                                                                 |
| ------------- | ------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scale`       | number | `1.0`   | Content scale for icons, spacing and base text size.                                                                                                                                        |
| `font_scale`  | number | `1.0`   | Text-only multiplier, `0.2` to `2.5`. Combined with the widget's normal scale and its own `font_scale`. Settings → Bar → Widgets → Font Scale.                                              |
| `font_weight` | int    | `500`   | CSS weight `100` to `1000` (400 regular, 700 bold) for widget labels.                                                                                                                       |
| `font_family` | string | `""`    | Typeface for this bar's widgets. Empty inherits the global [`font_family`](/noctalia/configuration/appearance/#font); `[widget.<name>] font_family` overrides it. Settings → Bar → Widgets. |

### Edges and corners

`concave_edge_corners = true` picks which pair of corners turns concave; `false` keeps all four convex. A floating bar (`margin_edge > 0`) can't be concave because it doesn't touch the edge.

For a full-length bar (`margin_ends = 0`), the two **inner-edge** corners facing away from the screen edge become concave:

| Bar position | Concave corners                             |
| ------------ | ------------------------------------------- |
| `top`        | `radius_bottom_left`, `radius_bottom_right` |
| `bottom`     | `radius_top_left`, `radius_top_right`       |
| `left`       | `radius_top_right`, `radius_bottom_right`   |
| `right`      | `radius_top_left`, `radius_bottom_left`     |

For an inset bar (`margin_ends > 0`), the two corners touching the screen edge become concave and the bar flares into the end margins. The carve is limited by the corner radius, half the `thickness`, and the available `margin_ends`.

### Dead zones

The dead zone is the bar margin outside the widget sections, usually the inset from `margin_ends`. It takes the same bindings as widgets under `[bar.<name>.dead_zone.actions]`:

```toml
# Bind gestures on the empty bar margin
[bar.default.dead_zone.actions]
left = "panel-toggle launcher"
middle = "exec kitty"
scroll_up = "volume-up"
scroll_down = "volume-down"
back = "media previous"
forward = "media next"
```

- All nine gestures are available. An action is an IPC command, `exec <command line>`, or `none`; see [Widget Actions](/noctalia/bar/actions/).
- Panel actions anchor at the pointer.
- Right-click opens Control Center unless you bind `right`. While an attached panel is open, right-click on the bar still toggles Control Center, unless the click lands in a dead zone with `right` bound.
- Per-monitor `[bar.<name>.monitor.<match>.dead_zone.actions]` replaces the bar's table rather than merging with it.

Set `click_through = true` under `[bar.<name>.dead_zone]` to let clicks in the dead zone reach the window underneath. This suits a transparent bar with only a few widgets.

```toml
# Pass dead-zone clicks through to windows
[bar.default.dead_zone]
click_through = true
```

- Only interactive widgets take input. Spacers and widgets with `interactive = false` pass clicks through too.
- Dead zone actions no longer fire.
- Auto-hide bars ignore `click_through`.
- Per-monitor overrides accept it under `[bar.<name>.monitor.<match>.dead_zone]`.

## Per-monitor overrides

Add named subtables under `[bar.<name>.monitor.*]`. **First match wins**, in file order.

```toml
# Bottom bar with fewer widgets on DP-1
[bar.default.monitor.dp1]
match              = "DP-1"
position           = "bottom"
enabled            = true
thickness          = 44
background_opacity = 0.9
compositor_blur    = false
border_width       = 1.0
radius             = 0
radius_top_left    = 12
radius_top_right   = 12
radius_bottom_left = 0
radius_bottom_right = 0
padding            = 20
widget_spacing     = 6
start              = []
center             = ["workspaces"]
end                = ["volume", "clock"]
```

`match` is compared against:

1. The exact connector name (`eDP-1`, `DP-1`, `HDMI-A-1`).
2. Any substring of the monitor description (`"LG"`, `"4K"`, `"DELL"`).

- `match` defaults to the subtable name, so `[bar.default.monitor."DP-1"]` works without it.
- Only the fields you set are overridden; the rest come from `[bar.*]`.
- Every bar field can be overridden, including `position`, `dead_zone`, `auto_hide`, `auto_hide_delay_ms`, `auto_hide_reserve_space`, `smart_auto_hide`, `show_on_workspace_switch`, `reserve_space`, `layer`, `scale`, `font_scale`, `background_opacity`, `compositor_blur`, `panel_overlap`, `color`, `font_family`, and all `capsule_*` keys.
- Use a per-monitor `panel_overlap` on mixed fractional-scale setups, since the right value depends on the output scale.
- For a per-monitor `font_scale` in Settings, select the monitor nested under the bar.

## Auto-hide

With `auto_hide = true`, the bar:

- Slides out once the pointer leaves it, and slides back in when the pointer reaches the matching screen edge.
- Waits `auto_hide_delay_ms` (0 to 600000) after the pointer leaves before hiding; returning cancels the wait. The delay doesn't apply to Smart mode, `bar-hide`, or the workspace-switch peek.
- With `show_on_workspace_switch = true` (default), briefly reveals when the active workspace changes on that monitor.
- Reveals from the physical screen edge even when floating (`margin_edge > 0`).

`reserve_space` decides whether the bar keeps a compositor gap:

| `auto_hide` | `reserve_space = true`              | `reserve_space = false`          |
| ----------- | ----------------------------------- | -------------------------------- |
| `false`     | Windows are pushed away.            | Bar overlays fullscreen clients. |
| `true`      | Gap stays while the bar slides out. | Bar retracts as an overlay.      |

Set `auto_hide_reserve_space = true` (**Reserve Space While Visible**) to reserve the gap only while an auto-hidden bar is on screen. It works with pointer and Smart auto-hide, requires `reserve_space = true`, defaults to `false`, and can be set per monitor.

### Smart auto-hide

Set auto-hide to **Smart** in bar settings, or `smart_auto_hide = true` with `auto_hide = false`. The bar stays visible while the active workspace on that monitor is empty and hides when it has windows.

- Minimised windows don't hide the bar on Umbriel, KDE Plasma, labwc, and compositors implementing `wlr-foreign-toplevel-management`. They still count toward occupancy and window counts.
- An open scratchpad with a non-minimised window counts as content.
- On labwc, occupancy is inferred from focus (see the [workspaces widget](widgets/workspaces)).
- Smart auto-hide wins if both `auto_hide` and `smart_auto_hide` are set.
- It uses the same slide animation and edge reveal strip.
- On Niri and Umbriel, the bar stays visible while overview is open.
- It re-evaluates on workspace changes, window open and close, and overview toggles.

### Layer

- `layer = "overlay"` shows the bar above fullscreen apps.
- `layer = "auto"` keeps the bar on Top, but promotes the bar and an attached panel (such as Control Center) to Overlay until the panel closes and the bar finishes hiding.
- Hot corners follow the bar's resting layer, so with `auto` they stay on Top.
- Floating panels keep their own layer, including when centered.

### IPC

- `bar-show`, `bar-hide`, `bar-toggle` and `bar-reserve-toggle` take optional `[bar-name] [monitor-selector]`; omit both to affect every bar. They change only the running shell, not the config.
- With `auto_hide`, they retract or reveal like pointer auto-hide, and edge reveal still works after `bar-hide`.
- With `auto_hide` off, `bar-hide` frees the compositor gap until `bar-show`, regardless of `reserve_space`.
- `bar-reserve-toggle` toggles the exclusive zone for matched bars; panels opened from them follow the temporary value.
- `bar-layer-set <top|overlay|auto> [bar-name] [monitor-selector]` switches the layer at runtime until the next bar config reload.

```kdl
// niri: peek the bar above a fullscreen window
binds {
    Mod+B { spawn-sh "noctalia msg bar-layer-set overlay"; }
    Mod+Shift+B { spawn-sh "noctalia msg bar-layer-set top"; }
}
```

## Widget Capsule

Each widget can have a capsule (pill-shaped background + optional border). Settings cascade from bar defaults down to per-widget overrides.

### Bar-level defaults

Set under `[bar.<name>]` or `[bar.<name>.monitor.*]`:

| Setting                | Type   | Default             | Description                                                                                                                                                                                                                                                                   |
| ---------------------- | ------ | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `capsule`              | bool   | `false`             | `true` gives every widget a capsule unless `[widget.*]` sets `capsule = false`.                                                                                                                                                                                               |
| `color`                | string | *(unset)*           | Default icon + label color role for every widget on this bar; fixed hex colors are also supported.                                                                                                                                                                            |
| `icon_color`           | string | *(unset)*           | Overrides `color` for icons only on this bar; fixed hex colors are also supported. When unset, icons inherit `color`.                                                                                                                                                         |
| `capsule_radius`       | number | *(auto pill)*       | Default capsule corner radius in logical pixels before `scale` is applied (clamped 0–80). Also used by workspace pills and taskbar workspace groups. Omit to use automatic pill radius.                                                                                       |
| `capsule_fill`         | string | `surface_container` | Default capsule background color role; fixed hex colors are also supported.                                                                                                                                                                                                   |
| `capsule_foreground`   | string | *(unset)*           | Default icon + label color role for capped widgets; fixed hex colors are also supported.                                                                                                                                                                                      |
| `capsule_padding`      | number | `6`                 | Inner padding in logical pixels before `scale` is applied (clamped 0–48).                                                                                                                                                                                                     |
| `capsule_opacity`      | number | `1.0`               | Capsule background opacity (0.0–1.0).                                                                                                                                                                                                                                         |
| `capsule_border`       | string | *(omitted)*         | Color role for the capsule border; fixed hex colors are also supported. If omitted, no border by default. If present as `""`, no border.                                                                                                                                      |
| `capsule_border_width` | number | `1`                 | Capsule outline thickness in logical pixels before `scale` is applied (clamped 0–8). Only drawn when `capsule_border` resolves to a color.                                                                                                                                    |
| `hover_highlight`      | bool   | `true`              | Softly tint the widget under the mouse pointer with its own foreground color. Works with and without capsules; inside a capsule group only the hovered member lights up. The highlight never changes widget layout or spacing. Set `false` to disable the effect on this bar. |
| `show_tooltip`         | bool   | `true`              | Show hover tooltips for widgets on this bar. Set `false` to turn tooltips off for every widget on this bar without disabling clicks or scrolls; a widget's own `show_tooltip` overrides it.                                                                                   |

| ---------------------- | ------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `font_scale`           | number  | `1.0`                     | Additional text-only multiplier for this widget, combined with the owning bar's `font_scale` (clamped 0.2–2.5).                                                                                                                                                                                                                                          |
| `anchor`               | bool    | `false`                   | Pin this widget as the center lane's alignment anchor.                                                                                                                                                                                                                                                                                                   |
| `font_family`          | string  | *(from bar)*              | Typeface for this widget. | `font_weight`          | integer | *(from bar)*              | CSS font weight `100`–`1000`. | `capsule`              | bool    | *(from bar)*              | Omit to inherit bar flag; `false` disables; `true` forces on.                                                                                                                                                                                                                                                                                            |
| `capsule_radius`       | number  | *(from bar)*              | Per-widget corner radius (0–80). | `capsule_padding`      | number  | *(from bar)*              | Per-widget inner padding (0–48).                                                                                                                                                                                                                                                                                                                         |
| `capsule_opacity`      | number  | *(from bar)*              | Per-widget capsule background opacity.                                                                                                                                                                                                                                                                                                                   |
| `capsule_border`       | string  | *(from bar)*              | Color role for the capsule border; fixed hex colors are also supported. Omit to inherit bar policy. Present but empty/whitespace-only = no border.                                                                                                                                                                                                       |
| `capsule_border_width` | number  | *(from bar)*              | Per-widget capsule outline thickness (0–8). Omit to inherit the bar value.                                                                                                                                                                                                                                                                               |
| `color`                | string  | *(unset)*                 | Icon + label color role with or without capsule; fixed hex colors are also supported. Resolution order: `color` → `capsule_foreground` → built-in defaults.                                                                                                                                                                                              |
| `icon_color`           | string  | *(unset)*                 | Overrides `color` for icons only. Resolution order for icons: `icon_color` → `color` → `capsule_foreground` → built-in defaults. | `interactive`          | bool    | `true` (spacers: `false`) | Set `false` to make the widget passive: hover highlight and tooltips are disabled, pointer events (clicks, scrolls) pass through to the bar underneath, and the **Actions** settings section is hidden. | `enabled`              | bool    | `true`                    | Show or hide this widget on the bar. Prefer color role names so widget styling follows the active palette. Role names use **snake_case** (e.g. `on_surface`, `surface_container`, `secondary`). Invalid role names or malformed hex colors are treated as config errors.

- The capsule hides automatically when a widget shows nothing (empty tray, absent battery).
- The workspaces widget reuses its resolved `capsule_radius` for workspace pills.
- The taskbar reuses it for workspace group capsules when `group_by_workspace = true`, even with its outer capsule disabled.

```toml
# Capsules on every widget, with per-widget tweaks
[bar.default]
capsule         = true
capsule_fill    = "surface_container"
capsule_opacity = 0.9
capsule_border  = "outline_variant"

# Accent bar: primary fill + matching text
[bar.accent]
capsule            = true
capsule_fill       = "primary"
capsule_foreground = "on_primary"
capsule_padding    = 10
capsule_radius     = 8.0

[widget.volume]
capsule_fill   = "secondary"
capsule_radius = 0.0         # square this widget's capsule
capsule_border = ""          # no border on this widget

[widget.spacer]
type    = "spacer"
capsule = false
```

## Capsule groups

A **capsule group** renders several widgets inside one shared capsule with a common style. The group is a single item in the lane, so inserting widgets elsewhere never splits it. Manage groups in Settings:

1. Open **Settings → Bar → Bar Widgets**.
2. **Drag one widget onto the middle of another** to create a group. Or tick two or more widgets in the same lane and click **Group**; they need not be adjacent, and the group takes the place of the first. A style editor opens.
3. Edit background, border, foreground, padding, spacing, radius and opacity for all members at once.
   - **Accordion** collapses the group to its first widget until hovered.
   - **Reveal direction** picks the side the other widgets unfold on. Neighbors on the lane's end side stay put.
4. **Drag a widget onto the group** to add it; **drag a member out** or use its eject button to remove it. Drag members to reorder them, or drag the group's handle to move the whole group.
5. To dissolve a group, open its style editor and click **Ungroup** (its members return to the lane in place).

When dragging a widget, hovering the **middle** of another widget combines them into a group, while hovering the **top/bottom edge** drops it between widgets as a normal reorder.

Each group is stored as one `[[bar.<name>.capsule_group]]` table with an ordered `members` list and the shared style. The lane references it with a `group:<id>` token. You normally don't write these by hand:

```toml
# A three-widget group in the end lane
[bar.default]
end = ["clock", "group:g1", "session"]   # the group occupies one lane slot

[[bar.default.capsule_group]]
id      = "g1"
members = ["network", "bluetooth", "volume"]
fill    = "surface_container"
padding = 6.0
opacity = 0.9
enabled = true
accordion = true                         # optional: collapse to the first widget, reveal on hover
accordion_direction = "end"              # "end" (default) or "start"
widget_spacing = 10                      # optional: gap between this group's widgets
# border, foreground, radius, enabled are optional
```

| Setting               | Type    | Default                    | Description                                                                                                                                   |
| --------------------- | ------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                  | string  | *(required)*               | Group identifier. Lane entries reference the group with `group:<id>`.                                                                         |
| `members`             | list    | *(required)*               | Ordered list of widget names belonging to this group.                                                                                         |
| `enabled`             | bool    | `true`                     | Show or hide the entire group on the bar. Disabled groups are not populated and their widgets consume no resources.                           |
| `fill`                | string  | `surface_container`        | Background color role for the shared capsule; fixed hex colors are also supported.                                                            |
| `border`              | string  | *(omitted)*                | Color role for the capsule border; fixed hex colors are also supported. Omit for no outline; present but empty (`""`) also means no outline.  |
| `border_width`        | number  | `1`                        | Capsule outline thickness in logical pixels (clamped 0–8). Only drawn when `border` resolves to a color.                                      |
| `foreground`          | string  | *(unset)*                  | Icon + label color role for all widgets inside this group; fixed hex colors are also supported.                                               |
| `padding`             | number  | `6`                        | Inner padding between the capsule edge and its widgets, in logical pixels (clamped 0–48).                                                     |
| `radius`              | number  | *(auto pill)*              | Capsule corner radius in logical pixels (0–80). Omit for automatic pill radius.                                                               |
| `opacity`             | number  | `1.0`                      | Capsule background opacity (0.0–1.0).                                                                                                         |
| `accordion`           | bool    | `false`                    | Collapse the group to its first widget; hovering the capsule expands it in place to reveal the rest. Needs at least two widgets in the group. |
| `accordion_direction` | string  | `end`                      | Where the hidden widgets unfold relative to the first one along the lane: `end` (after it) or `start` (before it).                            |
| `accordion_duration`  | integer | `200`                      | Duration of the unfold and collapse animations in milliseconds (0–2000, 0 is instant).                                                        |
| `accordion_delay_ms`  | integer | `100`                      | Milliseconds to hover before unfolding starts (0–2000, 0 reacts at once; collapse begins without this delay).                                 |
| `widget_spacing`      | integer | *(bar's `widget_spacing`)* | Gap between the group's widgets, in logical pixels. Omit to inherit the bar's `widget_spacing`.                                               |

Override a group's style per monitor with `[[bar.<name>.monitor.<match>.capsule_group]]` tables using the same `id`. A reused widget name (such as several `spacer` instances) can sit in different groups, because membership is positional.
