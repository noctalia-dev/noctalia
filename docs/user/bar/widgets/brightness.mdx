Shows the current monitor brightness level and adjusts it via scroll wheel. By default, the widget hides itself when no controllable monitor is found. Click opens the display tab in the control center.

| Setting                 | Type | Default | Description                                                                              |
| ----------------------- | ---- | ------- | ---------------------------------------------------------------------------------------- |
| `show_glyph`            | bool | `true`  | Show the brightness glyph                                                                |
| `show_label`            | bool | `true`  | Show the brightness percentage next to the glyph (horizontal and vertical bars)          |
| `show_when_unavailable` | bool | `false` | Keep the widget visible with a subdued glyph when this monitor has no brightness control |

```toml
[widget.brightness]
show_glyph = true
show_label = false
show_when_unavailable = true
```

At least one of `show_glyph` or `show_label` must be `true`. With `show_glyph = false`, only the brightness percentage is displayed, without icon spacing.

When `show_when_unavailable` is enabled and brightness control is unavailable, the percentage is hidden and scrolling has no effect. If `show_glyph` is also disabled, the widget hides itself because there is no content to display.

See [`[brightness]`](/noctalia/services/brightness/) for backend configuration.
