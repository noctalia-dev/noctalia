title: custom_button

Shows a custom glyph/image and an optional label. What it does on click and scroll is set with [widget actions](/noctalia/bar/actions/).

| Setting                 | Type   | Default    | Description                                                                                         |
| ----------------------- | ------ | ---------- | --------------------------------------------------------------------------------------------------- |
| `glyph`                 | string | `"heart"`  | Bar glyph name: Noctalia alias, Tabler icon name, or `U+` / `0x` codepoint                          |
| `custom_image`          | string | `""`       | Path to a custom image displayed instead of the glyph. Leave empty to use the glyph                 |
| `custom_image_colorize` | bool   | `false`    | When `true`, tint the custom image with the widget icon color                                       |
| `label`                 | string | `""`       | Optional text label shown next to the glyph or image                                                |
| `glyph_position`        | string | `"before"` | Place the glyph or image `"before"` or `"after"` the label. See [Peek](/noctalia/bar/widgets/#peek) |
| `peek`                  | bool   | `false`    | Show only the glyph or image and reveal the label on hover. See [Peek](/noctalia/bar/widgets/#peek) |
| `peek_delay_ms`         | int    | `100`      | Hover time before the label reveals, from `0` to `2000` ms                                          |
| `tooltip`               | string | `""`       | Optional hover tooltip                                                                              |

```toml
[widget.quick-action]
type = "custom_button"
custom_image = "/path/to/icon.png"
custom_image_colorize = true
label = "Action"

[widget.quick-action.actions]
left = "exec notify-send Noctalia"
right = "exec notify-send 'Other action'"
```
