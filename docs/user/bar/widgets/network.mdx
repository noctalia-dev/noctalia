Shows the current network connection (Wi-Fi SSID and signal, wired, or cellular operator and signal) via NetworkManager. Disconnected and disabled states use the appropriate status glyph without dimming the widget. Left-click opens the Network tab in the control center; right-click disables or reconnects the active Wi-Fi, wired, or cellular connection.

With `peek = true`, the status glyph stays visible and the connection label reveals on hover, on the side set by `glyph_position`. In `vpn_status = "both"` mode, both glyphs stay visible while the network and VPN labels reveal together. Peek and glyph position controls are hidden when `show_label = false`. On vertical bars, labels remain truncated to three characters.

When NetworkManager starts after the shell or restarts, the widget follows it; while NetworkManager is stopped, the widget shows the disconnected glyph.

Hovering the widget shows a tooltip with the network name, signal strength, radio band, and interface. The band row (`2.4 GHz`, `5 GHz`, `6 GHz`, or `60 GHz`) appears only when the backend reports the connection frequency. NetworkManager and wpa_supplicant report it; iwd reports it when Station diagnostics provide a positive frequency.

When a cellular connection is the active one, the glyph shows live ModemManager signal bars and the label shows the operator name. An enabled modem that is not the active connection contributes extra tooltip rows (state, operator, signal, technology) instead; a powered-off modem is not shown. Cellular status requires ModemManager and is configured from the control center's [Cellular card](/noctalia/control-center/#cellular).

| Setting          | Type   | Default     | Description                                                                                                                              |
| ---------------- | ------ | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `show_label`     | bool   | `true`      | Show the SSID or interface name next to the glyph                                                                                        |
| `glyph_position` | string | `"before"`  | Place the glyph `"before"` or `"after"` its label. Peek reveals on the label's side; see [Peek](/noctalia/bar/widgets/#peek)             |
| `peek`           | bool   | `false`     | Show only status glyphs and reveal the enabled labels on hover                                                                           |
| `peek_delay_ms`  | int    | `100`       | Hover time before labels reveal, from `0` to `2000` ms                                                                                   |
| `vpn_status`     | string | `"replace"` | VPN indicator mode: `"replace"` swaps the network glyph for a shield, `"both"` shows both glyphs, and `"hidden"` disables the indicator. |
| `show_vpn_label` | bool   | `false`     | Show the VPN name when `vpn_status` is `"replace"` or `"both"` and labels are enabled.                                                   |

```toml
[widget.network]
show_label = false
```
