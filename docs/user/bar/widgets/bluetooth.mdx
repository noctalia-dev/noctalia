Shows the Bluetooth adapter state and connected device. Left-click opens the Bluetooth tab in the control center. Right-click toggles adapter power.

| Setting                         | Type   | Default    | Description                                                                                                                                                       |
| ------------------------------- | ------ | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `show_label`                    | bool   | `false`    | Show the connected device name next to the icon                                                                                                                   |
| `glyph_position`                | string | `"before"` | Place the icon `"before"` or `"after"` the device name. See [Peek](/noctalia/bar/widgets/#peek)                                                                   |
| `peek`                          | bool   | `false`    | Show only the icon and reveal the device name on hover. See [Peek](/noctalia/bar/widgets/#peek)                                                                   |
| `peek_delay_ms`                 | int    | `100`      | Hover time before the device name reveals, from `0` to `2000` ms                                                                                                  |
| `hide_when_adapter_off`         | bool   | `false`    | Hide the widget when the adapter is powered off. While hidden, the widget's right-click power toggle is unavailable; re-enable Bluetooth from the control center. |
| `hide_when_no_connected_device` | bool   | `false`    | Hide the widget when no Bluetooth device is connected.                                                                                                            |

```toml
[widget.bluetooth]
show_label = true
```
