The dock shows pinned and running apps. It's off by default; configure it in **Settings → Dock** or under `[dock]`.

```toml
# Turn on the dock with three pinned apps
[dock]
enabled = true
pinned  = ["firefox", "code", "kitty"]
```

## Dock settings

```toml
[dock]
colorize_icons      = false
enabled             = false
position            = "bottom"
active_monitor_only = false

icon_size           = 48
icon_shadow         = false
main_axis_padding   = 16
cross_axis_padding  = 8
item_spacing        = 6
background_opacity  = 0.88
compositor_blur     = true
border              = "outline_variant"
border_width        = 0.0
shadow              = true
radius              = 16
radius_top_left     = 16
radius_top_right    = 16
radius_bottom_left  = 16
radius_bottom_right = 16
concave_edge_corners = true
margin_ends         = 0
margin_edge         = 0

show_running        = true
auto_hide           = false
smart_auto_hide     = false
auto_hide_reveal_delay_ms = 250
reserve_space       = true
layer               = "top"

active_scale        = 1.0
inactive_scale      = 0.85
magnification       = true
magnification_scale = 1.45
active_opacity      = 1.0
inactive_opacity    = 0.85
icon_saturation     = 1.0
show_instance_count = true
show_dots           = false

launcher_position   = "none"
launcher_icon       = "grid-dots"
launcher_custom_image          = ""
launcher_custom_image_colorize = false

pinned = ["firefox", "code", "kitty"]
```

### Placement and behavior

| Setting                     | Type   | Default  | Description                                                                                         |
| --------------------------- | ------ | -------- | --------------------------------------------------------------------------------------------------- |
| `enabled`                   | bool   | `false`  | Show the dock.                                                                                      |
| `position`                  | string | `bottom` | `top`, `bottom`, `left` or `right`.                                                                 |
| `active_monitor_only`       | bool   | `false`  | Only show apps and windows from the active monitor.                                                 |
| `show_running`              | bool   | `true`   | Also show running apps that aren't pinned.                                                          |
| `pinned`                    | list   | `[]`     | Desktop entry IDs, `StartupWMClass` values or app names. See [`pinned` matching](#pinned-matching). |
| `margin_ends`               | int    | `0`      | Inset from each end along the main axis.                                                            |
| `margin_edge`               | int    | `0`      | Distance from the screen edge. Positive values float the dock.                                      |
| `auto_hide`                 | bool   | `false`  | Pointer auto-hide. See [Auto-hide](#auto-hide).                                                     |
| `smart_auto_hide`           | bool   | `false`  | Hide while the active workspace has windows.                                                        |
| `auto_hide_reveal_delay_ms` | int    | `250`    | Pointer dwell on the edge before revealing, 0 to 2000 ms. `0` reveals at once.                      |
| `reserve_space`             | bool   | `true`   | Reserve a compositor exclusive zone so windows are pushed away.                                     |
| `layer`                     | string | `top`    | `top` or `overlay`. `overlay` keeps the dock reachable above fullscreen apps.                       |

| `inactive_scale`                                                                   | number | `0.85`            | Icon scale for other apps, 0.1 to 1.0.                                                                                                                |
| `active_opacity`                                                                   | number | `1.0`             | Opacity for the focused app.                                                                                                                          |
| `inactive_opacity`                                                                 | number | `0.85`            | Opacity for other apps.                                                                                                                               |
| `magnification`                                                                    | bool   | `true`            | Magnify icons near the pointer. See [Magnification](#magnification).                                                                                  |
| `magnification_scale`                                                              | number | `1.45`            | Maximum scale at the pointer, 1.0 to 2.0. `1.0` turns magnification off.                                                                              |
| `show_instance_count`                                                              | bool   | `true`            | Badge with the window count when an app has 2+ windows.                                                                                               |
| `show_dots`                                                                        | bool   | `false`           | Running-window dots below icons.                                                                                                                      |

## Per-monitor overrides

Add named subtables under `[dock.monitor.*]`. First match wins in file order; omitted fields inherit from `[dock]`.

```toml
# Smaller dock on the laptop, left dock on the Dell
[dock.monitor.laptop]
match               = "eDP-1"
enabled             = true
icon_size           = 40
magnification_scale = 1.3
pinned              = ["firefox", "org.gnome.Nautilus"]

[dock.monitor.external]
match     = "DELL"
enabled   = true
position  = "left"
auto_hide = true
```

- `match` takes an exact connector name such as `eDP-1`, or a word-boundary token in the output description. It defaults to the subtable name, so `[dock.monitor."DP-1"]` works without it.
- Every dock setting can be overridden, including `enabled` and `pinned`.
- To show the dock only on some outputs, set global `enabled = false` and `enabled = true` in their overrides. Or keep it on globally and set `enabled = false` where you don't want it.
- When an override declares `pinned`, pinning or reordering on that dock updates `[dock.monitor.<name>].pinned`. Other docks update `[dock].pinned`.

In Settings, open **Dock** and choose **Monitor Override** in the sidebar. Unchanged values keep inheriting from the global Dock page.

:::note
The old `[dock].monitors` allow-list is migrated automatically to `enabled` overrides.
:::

## `pinned` matching

Each `pinned` entry is matched against desktop entries in this order:

1. Desktop entry ID stem (`"firefox"` matches `firefox.desktop` and `org.mozilla.Firefox.desktop`).
2. The entry's `StartupWMClass`.
3. The app `Name` (case-insensitive).
4. The full desktop entry path.

- With no match, a placeholder slot keeps the dock position.
- Running apps match by app ID and desktop-entry metadata. Token matching ignores the publisher namespace, so `dev.noctalia.luciole` doesn't match `dev.noctalia.Noctalia`.
- A running app with no desktop entry keeps its own ID and a generic icon.

## Icon colorization

Set `colorize_icons = true` to tint dock icons with `[shell].app_icon_color`. It can be overridden per monitor. Set the color in **Settings → Appearance → Interface**; see [App icon colorization](/noctalia/configuration/appearance/#app-icon-colorization).

## Active app emphasis

- The focused app uses `active_scale` and `active_opacity`.
- All other apps use `inactive_scale` and `inactive_opacity`.
- Focus changes animate smoothly between the two states.

## Window actions and minimise state

- Left-click an app with no windows to launch it. With one window, left-click focuses or restores it. Apps with several windows cycle through them.
- On Umbriel, KDE Plasma, labwc, and compositors implementing `wlr-foreign-toplevel-management`, clicking the focused window minimises it when allowed.
- Minimised windows stay running and in window counts.
- A small dash marks an app whose windows are all minimised, even with `show_dots = false`. With mixed states, the tooltip says how many are minimised.
- Right-click for per-window **Minimise** or **Restore**.

Minimise features need a compositor backend that reports window state; no configuration is needed.

## Magnification

With `magnification = true`, icons grow as the pointer moves along the dock, most under the pointer and less with distance.

- `magnification_scale` sets the maximum; `1.0` disables it.
- It applies on top of `active_scale` and `inactive_scale`.
- Icons may extend past the dock background; the background keeps its size.
- The launcher button magnifies too.
- Hovering shows a tooltip with the app name (**Launcher** for the launcher button).

## Reordering pinned apps

1. Press and hold a **pinned** icon for about 300 ms.
2. Drag it along the dock. Neighbors shift to show where it will land.
3. Release to save the order to `settings.toml`.

- Running-only apps can't be dragged. An app that's both running and pinned can.
- Leaving the dock while dragging cancels the reorder.

## Auto-hide

Dock settings offer **Off**, **On** and **Smart** as one control:

| Mode      | Config                                         |
| --------- | ---------------------------------------------- |
| **Off**   | `auto_hide = false`, `smart_auto_hide = false` |
| **On**    | `auto_hide = true`                             |
| **Smart** | `smart_auto_hide = true`, `auto_hide = false`  |

- **On** slides the dock out when the pointer leaves and back in at the screen edge.
- In both modes, the pointer must rest on the edge for `auto_hide_reveal_delay_ms` before the dock reveals.

`reserve_space` decides whether the dock keeps a compositor gap:

| Auto-hide | `reserve_space = true`               | `reserve_space = false`           |
| --------- | ------------------------------------ | --------------------------------- |
| Off       | Windows are pushed away.             | Dock overlays fullscreen clients. |
| On/Smart  | Gap stays while the dock slides out. | Dock retracts as an overlay.      |

### Smart auto-hide

The dock stays visible while the active workspace on that monitor is empty and hides when it has windows.

- Minimised windows don't hide the dock on Umbriel, KDE Plasma, labwc, and compositors implementing `wlr-foreign-toplevel-management`. They still count toward occupancy and window counts.
- An open scratchpad with a non-minimised window counts as content. A reserving dock keeps its gap while hidden, so the scratchpad lays out inside it.
- Smart auto-hide wins if both modes are set.
- It uses the same slide animation and edge reveal strip.
- On Niri and Umbriel, the dock stays visible while overview is open.
