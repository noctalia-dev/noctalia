Add the following settings to your Umbriel configuration file, usually located at `~/.config/umbriel/config.toml`. Umbriel's packaged [`examples/config.toml`](https://github.com/noctalia-dev/umbriel/blob/main/examples/config.toml) is a useful reference for the complete configuration. Umbriel also provides dedicated documentation for [configuration](/umbriel/configuration/), [window rules](/umbriel/window-rules/), and [layer rules](/umbriel/layer-rules/).

## Autostart Noctalia

Add `noctalia` to the `autostart` array under `[general]`. Preserve any commands that are already in the array:

```toml
[general]
autostart = ["noctalia"]
```

Umbriel runs these commands once after startup and does not run them again when its configuration is reloaded.

## Compositor Settings

These settings provide rounded windows, consistent borders, and a blurred compositor background:

```toml
[appearance]
prefer_no_csd = true
border_width = 2
corner_radius = 10

[appearance.blur]
enabled = true
optimized = true
passes = 2
radius = 3
noise = 0.02
brightness = 0.9
contrast = 0.9
saturation = 1.1
```

Adjust these values to match your preferred appearance. The full list of options is available in Umbriel's [Appearance](/umbriel/appearance/) and [Animation](/umbriel/animation/) references.

Keep `[animation.layers]` disabled, which is the default. Noctalia animates its own surfaces, and compositor layer animations running on top of them cause visual glitches.

## Window Rules

Use a `window_rule` to configure Noctalia's settings window as floating with a predictable size. Umbriel combines matching rules in file order, so add this to your existing rules or to a dedicated included file:

```toml
# Blur all windows
[[window_rule]]
blur = true
blur_optimized = true

# Float Noctalia's settings window
[[window_rule]]
match.app_id = "^dev.noctalia.Noctalia$"
default_floating = true
default_size = [1020, 900]
```

`match.app_id` is an ECMAScript regular expression. The `^` and `$` anchors make this rule apply only to Noctalia's settings window. See Umbriel's [Window Rules](/umbriel/window-rules/) reference for placement, workspace, opacity, blur, and focus options.

## Layer Rules and Blur

Noctalia publishes blur regions for its layer-shell surfaces when the compositor supports the `ext-background-effects` protocol. Enable blur for the bar, notifications, dock, panels, and OSD with the layer rule from Umbriel's example configuration:

```toml
[[layer_rule]]
match.namespace = "^noctalia-(bar-[^\"]+|notification|dock|panel|attached-panel|osd)$"
blur = true
blur_ignore_alpha = 0.6
blur_optimized = false
```

The namespace expression targets Noctalia's standard surfaces without matching unrelated layer-shell clients. `blur_ignore_alpha = 0.6` avoids blurring highly transparent parts of a surface. `blur_optimized = false` makes this rule use the regular blur path instead of the optimized mode configured globally under `[appearance.blur]`.

Layer-surface blur is disabled by default in Umbriel. Inspect active namespaces with:

```sh
umbriel layers
```

For the complete set of layer-rule options, see Umbriel's [Layer Rules](/umbriel/layer-rules/) reference.

## IPC Keybinds

Umbriel can launch Noctalia IPC commands directly from its `[keybinds]` table. Add these bindings to `~/.config/umbriel/config.toml`:

```toml
[keybinds]
"Mod+Space" = "spawn noctalia msg panel-toggle launcher"
"Mod+S" = "spawn noctalia msg panel-toggle control-center"
"Mod+Comma" = "spawn noctalia msg settings-toggle"
"Alt+Tab" = "spawn noctalia msg window-switcher hold"
"Alt+Shift+Tab" = "spawn noctalia msg window-switcher hold reverse"
"Mod+Shift+A" = "spawn noctalia msg screenshot-annotate"
"Mod+Ctrl+A" = "spawn noctalia msg annotate"

"XF86AudioRaiseVolume" = "spawn noctalia msg volume-up"
"XF86AudioLowerVolume" = "spawn noctalia msg volume-down"
"XF86AudioMute" = "spawn noctalia msg volume-mute"
"XF86MonBrightnessUp" = "spawn noctalia msg brightness-up"
"XF86MonBrightnessDown" = "spawn noctalia msg brightness-down"
```

`Mod` uses Umbriel's configured modifier from `general.mod_key` and defaults to Super in a native session. See [Keybinds](/umbriel/keybinds/) for more Noctalia IPC examples and the complete action reference.

## Window minimisation

Noctalia tracks Umbriel's minimise state in the [taskbar](/noctalia/bar/widgets/taskbar/), [dock](/noctalia/dock/), window switcher, and launcher window results. Clicking a focused single-window taskbar or dock icon minimises it when Umbriel marks it as eligible. Clicking a minimised window restores and focuses it; multi-window icons continue cycling.

Use an Umbriel build that includes both boolean fields `minimized` and `minimizable` in its window IPC snapshots. If those fields are missing or invalid, or the IPC connection is unavailable, minimise state and controls remain unavailable. Missing or invalid fields are reported in Noctalia's logs; update Umbriel when using an older build.

## Optional Type to Launch

Noctalia can open its launcher when you start typing in umbriel's overview.

A launcher opened by typing closes automatically when you leave the overview. Launchers opened normally are unaffected.

```toml
[shell]
umbriel_overview_type_to_launch_enabled = true
```

You can also enable this from **Settings → Umbriel → Overview**.

## Optional Close on Launch

Close the overview when opening an app from the launcher.

```toml
[shell]
umbriel_overview_close_on_launch_enabled = true
```

Only launching an application (a desktop entry or one of its desktop actions) closes the overview; other launcher results such as calculator or emoji do not. You can also enable this from **Settings → Umbriel → Overview**.

## Audio-reactive Effects

Enable **Settings → Umbriel → Audio → Provide Audio to Umbriel** to let Umbriel's audio-reactive effects respond to your audio. This is disabled by default. You can also enable it in Noctalia's configuration:

```toml
[shell]
umbriel_audio_provider_enabled = true
```

Enable an audio-reactive effect in Umbriel to see a response. No Noctalia visualizer widget is required.

## Window overview

On Umbriel builds supporting `overview-spread` and `[overview.spread]`, **Settings → Umbriel → Window Overview** offers **Customize Window Overview**. Enable it to save preferences in Noctalia and apply them to Umbriel at startup and when changed. Disable it to release Noctalia’s runtime override and return to Umbriel’s configuration file. Existing Umbriel installations keep their configuration until customization is enabled.

Choose current/all workspaces and monitor presentation: **Current monitor** keeps each window’s preview on its own monitor; **All monitors** gathers previews on the invoking monitor. Workspace filtering remains independent. Adjust preview spacing and maximum scale, window titles, workspace numbers, and close buttons. **Overview Background** adds dimming across monitors, background blur and strength, and **Overview Style Wallpaper**, with a separate **Wallpaper Dimming** slider. Every monitor gets the inset wallpaper effect in both monitor modes, including screens whose windows are gathered onto the invoking monitor. Background blur requires Umbriel’s global appearance blur; client-window transparency and blur remain independent.

These controls require the Umbriel spread feature; older compositors keep the existing settings page. The normal workspace overview still uses its own settings. Noctalia sends the complete spread table in one `config-set` request; it does not edit Umbriel’s files. Changing native settings dismisses an open overview, so reopen it to see the result.

Bind `Super+W` to `spawn noctalia msg window-switcher overview`. Alt+Tab can retain the carousel, and Super+Tab can retain Umbriel’s workspace overview.

**Animation Duration (ms)** controls the window overview’s entry and exit transitions, including its background, from 0 to 2000 milliseconds in 25 ms steps (default 250 ms). Zero makes them instant. Umbriel’s configured overview curve is preserved, including spring curves; its animation enable switches still apply. The normal workspace overview keeps its own timing.

Enable **Show Docks** to reveal auto-hidden Noctalia docks on every monitor while the window overview is open. Closing it restores each dock’s usual auto-hide or smart auto-hide behavior. Disabled docks stay disabled. This option is off by default, applies immediately, and does not change the normal workspace overview or saved dock settings.

The **Show App Search** toggle adds a centered search field above the window overview on the invoking monitor. Start typing to search installed applications through Noctalia's application provider. The rounded field and results have background blur, and results show small application icons. Up/Down or Tab selects a result, and Enter or a click launches it. Escape first clears a query, then closes the overview. The existing **Close on Launch** preference applies. With an empty query, arrows, Tab/Shift+Tab, Enter, Delete, and Escape continue to navigate the native window overview. This requires Umbriel's `overview-key` IPC command; older spread builds retain click-to-search. This shell preference is not written to Umbriel's configuration.

Umbriel uses layer rules for shell blur. Add this alongside your existing `layer_rule` entries (global appearance blur must also be enabled):

```toml
# Blur the overview search field and results, including windows behind them.
[[layer_rule]]
match.namespace = "^noctalia-overview-search$"
blur = true
blur_ignore_alpha = 0.1
blur_optimized = false
```
