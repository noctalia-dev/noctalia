Add the following settings to your Hyprland Lua configuration file (usually found at `~/.config/hypr/hyprland.lua`).

## Autostart Noctalia

Add this to your `hyprland.start` event hook:

```lua
hl.on("hyprland.start", function()
  hl.exec_cmd("noctalia")
end)
```

## Compositor Settings

Add the following to your existing `hl.config({})` block. These settings are for general window appearance and functionality.

```lua
hl.config({
  general = {
    gaps_in = 5,
    gaps_out = 10,
  },

  decoration = {
    rounding = 20,
    rounding_power = 2,

    shadow = {
      enabled = true,
      range = 4,
      render_power = 3,
      color = 0xee1a1a1a,
    },

    blur = {
      enabled = true,
      xray = true,
      size = 3,
      passes = 2,
      vibrancy = 0.1696,
    },
  },
})
```

## Persistent Workspaces

For the best workspace indicator behavior, make your regular Hyprland workspaces persistent. This keeps empty workspaces visible in Noctalia instead of only showing workspaces that currently contain windows.

Update the monitor name and workspace list to match your setup. You can find more syntax and examples in the official [Workspace Rules](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) documentation.

```lua
hl.workspace_rule({ workspace = "1", monitor = "DP-1", persistent = true, default_name = "web" })
hl.workspace_rule({ workspace = "2", monitor = "DP-1", persistent = true, default_name = "code" })
hl.workspace_rule({ workspace = "3", monitor = "DP-1", persistent = true, default_name = "chat" })
hl.workspace_rule({ workspace = "4", monitor = "DP-1", persistent = true, default_name = "game" })
hl.workspace_rule({ workspace = "5", monitor = "DP-1", persistent = true, default_name = "design" })
```

## IPC Keybinds

Add these binds to your `hyprland.lua`:

```lua
local mainMod = "SUPER"
local ipc = "noctalia msg "

-- Core binds
hl.bind(mainMod .. "+Space", hl.dsp.exec_cmd(ipc .. "panel-toggle launcher"))
hl.bind(mainMod .. "+S", hl.dsp.exec_cmd(ipc .. "panel-toggle control-center"))
hl.bind(mainMod .. "+comma", hl.dsp.exec_cmd(ipc .. "settings-toggle"))
hl.bind("ALT + Tab", hl.dsp.exec_cmd(ipc .. "window-switcher hold"))
hl.bind("ALT + SHIFT + Tab", hl.dsp.exec_cmd(ipc .. "window-switcher hold reverse"))

-- Media keys
hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd(ipc .. "volume-up"))
hl.bind("XF86AudioLowerVolume", hl.dsp.exec_cmd(ipc .. "volume-down"))
hl.bind("XF86AudioMute", hl.dsp.exec_cmd(ipc .. "volume-mute"))
hl.bind("XF86MonBrightnessUp", hl.dsp.exec_cmd(ipc .. "brightness-up"))
hl.bind("XF86MonBrightnessDown", hl.dsp.exec_cmd(ipc .. "brightness-down"))

-- Noctalia Settings
hl.window_rule({
    match = { class = "dev.noctalia.Noctalia" },
    float = true,
    size = { 1080, 920 },
})
```

## Touchpad gesture control

Hyprland 0.56.2 or later supports live Lua gesture callbacks. The following opt-in bindings use three fingers to switch workspaces, four fingers vertically to adjust output volume continuously, and four fingers horizontally to toggle media playback. Remove existing bindings for the same finger count and direction before adding these.

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })

local volumePending = 0
local volumeLastSent = 0
local volumePerUnit = 0.125

local function flushVolume(timeMs)
  if math.abs(volumePending) < 0.01 then return end
  local command = volumePending > 0 and "volume-up " or "volume-down "
  hl.exec_cmd("noctalia msg " .. command .. string.format("%.4f%%", math.abs(volumePending)))
  volumePending = 0
  volumeLastSent = timeMs
end

hl.gesture({
  fingers = 4,
  direction = "vertical",
  action = {
    start = function(e)
      volumePending = 0
      volumeLastSent = e.time_ms - 24
      -- The first delta also arrives in update; count it only there.
    end,
    update = function(e)
      volumePending = volumePending - e.delta.y * volumePerUnit
      if e.time_ms - volumeLastSent >= 24 then flushVolume(e.time_ms) end
    end,
    finish = function(e)
      if not e.cancelled then flushVolume(e.time_ms) end
      volumePending = 0
    end,
  },
})

hl.gesture({
  fingers = 4,
  direction = "horizontal",
  action = function() hl.exec_cmd("noctalia msg media toggle") end,
})
```

Up raises volume and down lowers it. `volumePerUnit` controls sensitivity: `0.125` changes volume by one percentage point per eight vertical gesture units. Movement is accumulated between updates, so the same distance produces the same change regardless of swipe speed, until the output reaches its volume limit. Updates are coalesced while moving and any remaining fraction is applied on release; there is no acceleration or repeat timer. The normal Noctalia volume OSD follows the changes.

If three-finger swipes act as dragging instead, set `input.touchpad.drag_3fg = 0` in your existing `hl.config` input settings. These bindings use swipes, not four-finger taps; Hyprland's live swipe callbacks do not provide tap recognition. See the official [Hyprland gesture documentation](https://wiki.hypr.land/configuring/core/binds/gestures/) for other bindings.

## Blur

Enable blur for Noctalia's bar, panels, dock, and notifications. We also disable Hyprland's built-in layer animations for Noctalia so they do not interfere with Noctalia's own animations.

<ImageLightbox src={blur1} alt="Blurred Noctalia surfaces" />

```lua
hl.layer_rule({
  name = "noctalia",
  match = {
    namespace = "^noctalia-(bar-.+|notification|dock|panel|attached-panel|osd|window-switcher)$",
  },
  no_anim = true,
  ignore_alpha = 0.5,
  blur = true,
  blur_popups = true,
})
```
