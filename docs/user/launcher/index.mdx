The launcher is one search box for your applications, system actions, and utility providers. Configure it under **Settings → Panels → Launcher**, or in `[shell.launcher]` (see [Configuration](#configuration)).

```toml
# Full layout, toolbar at the bottom, opening on Recent
[shell.launcher]
layout = "full"
search_position = "bottom"
default_view = "recent"
```

## Layout

`shell.launcher.layout` picks one of two layouts.

- **Full** (default): search plus views for Recent, Pinned, All, Categories, and Providers. Pinned appears when at least one app is pinned.
- **Simple**: a search field, an optional row of category chips (All, Recently Used, app categories), and results at a fixed 560 × 500 size. Pinned apps lead the list when the search is empty. Set `categories = false` to hide the chips.

### Full layout toolbar

- The toolbar holds the profile avatar (left), the search field (center), and the session shortcut (right). Hover the avatar to see your name and distro.
- Hiding the session shortcut lets the search field take its space. `search_position = "top"` moves the whole toolbar above the results.
- The avatar shares **Settings → Shell → General → Circular Avatar** with Control Center. Set `[shell].circular_avatar = false` to follow the shell's corner roundness.
- View tabs sit on the left. On the right are buttons for usage ordering and grid view, then the optional Settings shortcut.
- The grid/list and ordering buttons show the mode they will switch to. They change the same persistent options as Settings.
- The ordering button appears for All, Categories, and search results while `track_usage` is on. It is hidden for Recent, Pinned, Providers, and session actions.
- Turning usage ordering off still records frequency and recent launches. The selected result stays visible when you change ordering.

### Views and tabs

- The `default_view` tab comes first; the others keep their order, with Providers last. For example, `default_view = "all"` gives All, Recent, Pinned, Categories, Providers. If that view is unavailable, the launcher opens All.
- **All** is a flat list. With an empty search it shows pinned apps first, in pinned order, then the rest.
- **Categories** adds a second row for switching between desktop-entry categories.
- At narrow widths the view tabs show icons only; hover a tab to see its name.
- The Simple layout keeps its chip order.

## How search works

As you type, Noctalia queries all active **launcher providers**. A provider is either global (always searched) or prefixed (triggered by a keyword).

- **Global providers** such as Applications and Calculator merge their results, sorted by relevance.
- **Prefixed providers** such as Emoji and Wallpaper take over the results when their prefix starts the query.

Type `/` alone to see an overview of prefixed providers. Activating one inserts its prefix.

### Usage-based boosting

The launcher counts how often you activate results such as applications and wallpapers. Frequently used items rank higher, even for partial queries.

### Application categories

The **Categories** view (tag icon) switches between desktop-entry categories such as Internet, Development, Games, Office, System, and Utilities.

- Category tabs show icons and text. Enable **Category Icons Only** (`category_icons_only = true`) to hide the text; tooltips still show names.
- This applies to application and provider category filters in both layouts. Emoji categories in Full always use icons only.

:::note[Application options]
Right-click an application result to open its per-app options. **Shift + Validate** (default `Shift+Return`) opens the same menu.
:::

## Providers

### Applications

The main provider for finding and launching installed apps.

- **Source**: `.desktop` entries from the XDG directories, such as `/usr/share/applications` and `~/.local/share/applications`.
- **Search**: matches name, generic name, keywords, and categories, with fuzzy scoring boosted by activation count.
- **Grid**: with `app_grid = true`, grid-capable results (applications, `/emo`, `/wall`, `/session`) use an icon grid with names underneath. Left/right move between columns, up/down between rows.
- **Desktop actions**: `show_app_actions = true` lists `.desktop` actions next to applications. They are always available from the right-click menu.
- **Pinned apps**: the Pinned view follows your manual order. Drag a pinned app onto another to reorder. Pin markers show in list and grid views.
- **Terminal apps**: entries with `Terminal=true` run in a terminal. Set `export TERMINAL=wezterm` (or another emulator on `PATH`), without `-e`. See [General settings: Applications](/noctalia/configuration/general/#applications).

Package origins (Flatpak, Snap, Nix, AppImage) are marked on results when the desktop entry or executable shows them.

- AppImages are recognized by `X-AppImage-Version` or executable evidence, including extensionless files from AppImageLauncher or Gear Lever.
- The executable comes from `TryExec`, or from `Exec` after any `env VAR=value` prefix.
- Other `X-AppImage-*` keys alone do not mark an AppImage. `X-AppImage-Integrate=false` opts an entry out.

### Calculator

An expression evaluator powered by [`libqalculate`](https://qalculate.github.io/).

- **Prefix**: `/calc`. Also global: it triggers when the query contains a digit. `/calc` also accepts digit-free expressions such as `/calc EUR`.
- **Functions**: arithmetic and functions (`sin`, `cos`, `sqrt`, `pi`, `e`, …), units (`10 cm to in`), number bases (`0xff`), and currency (`10 USD to EUR`).
- **Locale**: decimal and thousands separators follow the system numeric locale, for example `10000,50+2000,25` under `pt_BR`.
- **Enter** copies the result to the clipboard.
- **Currency rates**: refreshed in the background while `fetch_exchange_rates` is on and `[shell].offline_mode` is off. Otherwise the last cached rates are used.
- **User definitions**: constants, functions, and units in `$XDG_DATA_HOME/qalculate/definitions/` (default `~/.local/share/qalculate/definitions/`) are available. Edit them by hand or with [Qalculate! (GTK)](https://github.com/Qalculate/qalculate-gtk); changes apply the next time the launcher opens.

### Emoji

Find and copy emojis.

- **Prefix**: `/emo`, for example `/emo heart`.
- **Search**: by name, category, and keywords. Activating a result copies the emoji.
- **Unicode characters**: common characters (punctuation, arrows, math, Greek, box drawing) are listed in a Unicode category, searchable by name or codepoint (`/emo em dash`, `/emo u+2014`).
- **Categories**: both layouts show category filters under `/emo`. Pick one to browse or narrow a search; All shows every category.
- **Usage**: with `track_usage`, **Recently Used** lists recent picks newest first. With `sort_by_usage` too, frequent picks rise to the top of an empty `/emo`.

### Panels

Open or close any panel without knowing its `noctalia msg panel-toggle` id.

- **Prefix**: `/pan`.
- **Source**: every registered panel (built-in or from an enabled plugin), plus one row per visible Control Center tab.
- **Activation**: a panel result toggles it; a tab result opens Control Center on that tab. Activation count boosts the score.
- **Ignored panels**: `shell.launcher.panels.ignored` hides panel ids from the list. Edit it under **Settings → Panels → Launcher → Providers**.

### Wallpaper

Browse and apply wallpapers from your configured directories.

- **Prefix**: `/wall`.
- **Source**: the directories in your [`[wallpaper]`](/noctalia/desktop/wallpaper/) config.
- **Activation**: filters by file and parent directory name. Activating applies the wallpaper to all monitors and updates the theme when `wallpaper` is the theme source.

### Session

Run enabled session menu actions.

- **Prefix**: `/session`.
- **Source**: your `shell.session.actions` entries, with their labels, icons, and commands (see [Session menu](/noctalia/desktop/session-menu/#actions)).
- **Activation**: runs the action exactly as the session panel does, including configured hooks.

### Windows

Find and focus an open window.

- **Prefix**: `/win`.
- **Source**: windows the compositor reports on every monitor and workspace, fuzzy-matched by title and app id.
- **Activation**: focuses the window, switching workspace if needed.
- **Minimised windows**: on Umbriel, KDE Plasma, labwc, and other compositors with `wlr-foreign-toplevel-management`, results can show a **Minimised** status. Activating one restores it.

## Dmenu mode

`noctalia dmenu` is a stdin/stdout picker for scripts:

```sh
# Pick one of three lines
printf 'alpha\nbeta\ngamma\n' | noctalia dmenu -p "Pick"
```

- It prints the selected line and exits `0`. Escape or closing the launcher prints nothing and exits `1`.
- `-p` / `--prompt` sets the input placeholder.
- A tab in a line splits it into title and description; the full line is still returned.
- If no candidate matches, Enter returns the typed text.
- Noctalia must be running on the same `XDG_RUNTIME_DIR` and `WAYLAND_DISPLAY`.

## Text editing shortcuts

With `shell.readline_shortcuts` enabled (Settings → Shell → General), every text field, including the launcher input, supports these shortcuts. Otherwise `Ctrl+A` selects all and `Ctrl+U` clears the field.

| Shortcut            | Action                                  |
| ------------------- | --------------------------------------- |
| `Ctrl+A`            | Move caret to start of line             |
| `Ctrl+E`            | Move caret to end of line               |
| `Ctrl+B` / `Ctrl+F` | Move caret back / forward one character |
| `Alt+B`             | Move caret to start of previous word    |
| `Alt+F`             | Move caret to end of next word          |
| `Ctrl+W`            | Delete previous word                    |
| `Ctrl+U`            | Clear backward to start of line         |
| `Ctrl+K`            | Delete from caret to end of line        |
| `Alt+D`             | Delete next word                        |

## Configuration

Launcher keys live in `[shell.launcher]`. Other sections also affect it:

- [Shell keybinds](/noctalia/configuration/keybinds/): navigation (`up`, `down`), activation (`validate`, `cancel`), and category cycling (`category_next`, `category_previous`).
- [Accessibility](/noctalia/configuration/general/#accessibility) `ui_scale` and [Font](/noctalia/configuration/appearance/#font) `font_family`: size and typeface.
- [App icon colorization](/noctalia/configuration/appearance/#app-icon-colorization): the `[shell].app_icon_color` used by `colorize_icons`.
- [Wallpaper](/noctalia/desktop/wallpaper/): search paths for the Wallpaper provider.
- [Session menu actions](/noctalia/desktop/session-menu/#actions): actions for the Session provider.

```toml
# Launcher defaults
[shell.launcher]
layout = "full"
width = 760
search_position = "bottom"
default_view = "recent"
categories = true
category_icons_only = false
show_navigation_labels = true
show_settings_button = true
show_session_button = true
show_icons = true
show_app_origin_indicator = true
compact = false
app_grid = false
colorize_icons = false
show_app_actions = false
track_usage = true
sort_by_usage = true
ignore_mouse = false
pinned = []
fetch_exchange_rates = true
auto_paste = "auto"
provider_prefix = "/"
```

### Layout and display

| Key                         | Default    | Description                                                                                                                                                                                                                        |
| --------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `layout`                    | `"full"`   | `full` or `simple`. See [Layout](#layout).                                                                                                                                                                                         |
| `width`                     | `760`      | Full only. Panel width in pixels, `560` to `1100`.                                                                                                                                                                                 |
| `search_position`           | `"bottom"` | Full only. Toolbar position: `top` or `bottom`.                                                                                                                                                                                    |
| `default_view`              | `"recent"` | Full only. View on open: `recent`, `pinned`, `all`, or `categories`. Its tab comes first; falls back to All when the view is empty.                                                                                                |
| `categories`                | `true`     | Simple only. Show the All, Recently Used, and category chips. Launchers scoped to one provider, such as dmenu pickers, keep their chips.                                                                                           |
| `category_icons_only`       | `false`    | Hide text on application and provider category filters in both layouts; tooltips keep names. Does not affect the main view tabs.                                                                                                   |
| `show_navigation_labels`    | `true`     | Full only. Text on the Recent, Pinned, All, Categories, and Providers tabs. Narrow panels use icons regardless.                                                                                                                    |
| `show_settings_button`      | `true`     | Full only. Show the Settings shortcut.                                                                                                                                                                                             |
| `show_session_button`       | `true`     | Full only. Show the session-actions shortcut.                                                                                                                                                                                      |
| `show_icons`                | `true`     | Application icons in result rows. Prefixed-provider rows such as emoji keep their leading character.                                                                                                                               |
| `show_app_origin_indicator` | `true`     | Package-origin overlays (Flatpak, Snap, Nix, AppImage) on application results.                                                                                                                                                     |
| `compact`                   | `false`    | Smaller icons, tighter padding, single-line rows without subtitles.                                                                                                                                                                |
| `app_grid`                  | `false`    | Icon grid for Applications, Emoji, Wallpaper, Session, and the provider overview. Other providers, and global searches with any list result, use lists. The toggle is hidden for list-only providers and when `show_icons` is off. |
| `colorize_icons`            | `false`    | Tint application and window result icons with `[shell].app_icon_color`. Wallpaper thumbnails and other provider images keep their colors.                                                                                          |

Settings → Panels → Launcher (Display).

### Behavior

| Key                    | Default  | Description                                                                                                                                                                       |
| ---------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `show_app_actions`     | `false`  | List searchable `.desktop` actions next to applications, shown with the parent app name.                                                                                          |
| `track_usage`          | `true`   | Record local history for **Recent** and usage ordering. Off stops recording, hides Recent, and disables usage ordering; stored history is kept.                                   |
| `sort_by_usage`        | `true`   | While tracking, boost frequent applications, emoji, panels, wallpapers, and dmenu entries. Same setting as the ordering button.                                                   |
| `ignore_mouse`         | `false`  | Ignore hover, clicks, scrolling, and touch inside the launcher and its menus. Clicking outside still closes it.                                                                   |
| `pinned`               | `[]`     | Ordered desktop entry IDs for the **Pinned** view. Independent of `dock.pinned` and taskbar `pinned` lists.                                                                       |
| `fetch_exchange_rates` | `true`   | Refresh currency rates from libqalculate's third-party online sources. Off uses the last cached rates.                                                                            |
| `auto_paste`           | `"auto"` | Paste after copy-style activations (calculator, emoji, copy-mode dmenu): `off`, `auto`, `ctrl_v`, `ctrl_shift_v`, or `shift_insert`. Same values as `shell.clipboard_auto_paste`. |

Settings → Panels → Launcher. **Reset Usage Data** there clears stored usage history.

### Provider prefixes

Every prefixed provider (built-in, dmenu, or plugin) triggers on a shared prefix character plus a bare **trigger word**. With `provider_prefix = "/"` and the word `emo` you type `/emo`; with `"."` you type `.emo`.

```toml
# Built-in provider defaults
[shell.launcher.providers.calculator]
prefix = "calc"
global = true

[shell.launcher.providers.emoji]
prefix = "emo"

[shell.launcher.providers.panels]
prefix = "pan"

[shell.launcher.providers.session]
prefix = "session"
global = false

[shell.launcher.providers.wallpaper]
prefix = "wall"

[shell.launcher.providers.windows]
prefix = "win"

[shell.launcher.panels]
ignored = ["polkit", "setup-wizard", "test", "launcher"]
```

| Key                       | Default                                          | Description                                                                                                                                                                                                               |
| ------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `provider_prefix`         | `"/"`                                            | Common prefix character for every trigger word.                                                                                                                                                                           |
| `providers.<name>.prefix` | per provider                                     | Trigger word for `calculator`, `emoji`, `panels`, `session`, `wallpaper`, or `windows` (case-insensitive). Write it bare (`calc`, not `/calc`). `""` restores the built-in default; it does not make the provider global. |
| `providers.<name>.global` | `true` for `calculator`, else `false`            | Also include the provider in un-prefixed search.                                                                                                                                                                          |
| `panels.ignored`          | `["polkit", "setup-wizard", "test", "launcher"]` | Panel ids the Panels provider never lists. Setting it replaces the default list.                                                                                                                                          |

- Applications can't be prefixed and are always searched globally.
- Dmenu providers take their word from the entry's `prefix` and `global` keys; see [Persistent dmenu entries](#persistent-dmenu-entries).
- Plugin providers use their `[[launcher_provider]]` manifest `prefix`, overridable per user; see [Plugin provider overrides](#plugin-provider-overrides).

### Persistent dmenu entries

Config-defined dmenu providers make command palettes, script menus, or SSH host lists without writing a plugin. Each entry is a `[shell.launcher.dmenu.entry.<id>]` table, where `<id>` is a stable id. Entries hot-reload with the config.

```toml
# /ssh lists hosts from ~/.ssh/config and opens one in foot
[shell.launcher.dmenu.entry.ssh]
command = "awk '/^Host /{print $2}' ~/.ssh/config"
exec = "foot ssh {selection}"
prefix = "ssh"
glyph = "server"
global = false
```

| Key        | Default      | Description                                                                                                                                                           |
| ---------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `command`  | –            | Run through `/bin/sh -lc` once per launcher session; each stdout line is a result. A tab splits title and description. Optional for freeform entries.                 |
| `exec`     | –            | Run detached on activation. `{selection}` (the raw line) and `{query}` (text after the prefix) are inserted already shell-quoted. Without `exec`, the line is copied. |
| `prefix`   | –            | Bare trigger word such as `cmd`, combined with `provider_prefix`. If empty, set `global = true` or the entry is unreachable.                                          |
| `label`    | entry id     | Title in the provider overview.                                                                                                                                       |
| `glyph`    | `"terminal"` | Tabler glyph for every result.                                                                                                                                        |
| `global`   | `false`      | Also show results in un-prefixed search.                                                                                                                              |
| `freeform` | `false`      | Make non-empty typed text an activatable result.                                                                                                                      |

- Don't add quotes around `{selection}` or `{query}`; each becomes one shell word.
- `exec` does not open a terminal. For interactive commands, launch one yourself, for example `foot -e bash -lc 'pkexec dnf upgrade --refresh'`. Applications with `Terminal=true` differ: they use `$TERMINAL`.

```toml
# /notify Build finished runs: notify-send 'Build finished'
[shell.launcher.dmenu.entry.notify]
label = "Notify"
prefix = "notify"
glyph = "bell"
freeform = true
exec = "notify-send {query}"
```

### Plugin provider overrides

Plugin providers default to the `prefix` and `global` from their `[[launcher_provider]]` manifest entry. Override them with a table keyed by the fully-qualified `"<pluginId>:<entry>"` id; the plugin must be enabled.

```toml
# Trigger the plugin on /mp and include it in global search
[shell.launcher.providers."author/my-plugin:search"]
prefix = "mp"
global = true
```

Unknown provider names, disabled plugins, and two providers with the same prefix are reported as config warnings.

### From the Settings UI

Built-in providers are configurable under **Settings → Panels → Launcher → Providers**:

- **Common Prefix Character**: `provider_prefix`.
- **\<Provider> Prefix**: each built-in trigger word. Leave blank for the default.
- **\<Provider> in Global Search**: whether it also shows in un-prefixed search.
- **Ignored panels**: a picker for `panels.ignored`.

Dmenu and plugin prefixes are set only in the config.
