**This template is only compatible with Mango version 0.18.0 or higher.**

The built-in Mango template generates border colors for regular,
active, split, and urgent windows, and colors for jump label, and
group bar borders, as well as the scratchpad background, root window
background, and drop shadow of dragged windows.


## Setup

Enable **Mango** under **Settings → Templates → Compositors**.

Noctalia writes the rendered template to
`~/.config/mango/noctalia.toml` and appends the line
`source=~/.config/mango/noctalia.conf` to
`~/.config/mango/config.conf`.
If the Mango setting `auto_reload_config` is
enabled, Mango reloads both files automatically when they change.
