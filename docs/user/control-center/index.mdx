The Control Center is Noctalia's panel for session controls, system status, media, notifications, weather, and service-specific tools. Open it from the control-center bar widget, by right-clicking empty space on a bar, or with IPC:

```sh
# Toggle the Control Center
noctalia msg panel-toggle control-center
```

Pass a context to jump straight to a tab:

```sh
# Open on a specific tab
noctalia msg panel-toggle control-center audio
noctalia msg panel-open control-center system
```

## Sidebar

The `[control_center]` section sets the sidebar style, panel width, and Home tab extras. Settings → Control Center edits these options.

```toml
# Compact icon-only sidebar
[control_center]
sidebar = "compact"
sidebar_section = "compact"
width = 700
show_shortcut_labels = true
show_session_button = true
show_avatar_border = true
hidden_tabs = []
```

| Option                 | Type   | Default     | Description                                                                                                                                                                                                   |
| ---------------------- | ------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sidebar`              | string | `"compact"` | Sidebar when opening on **Home** (control center widget, bar background click, or `noctalia msg panel-toggle control-center` with no tab): `"full"` (icons and labels), `"compact"` (icons only), or `"none"` |
| `sidebar_section`      | string | `"compact"` | Sidebar when opening straight to a tab (volume, network, and media bar widgets, or `noctalia msg panel-toggle control-center audio`). Same values as `sidebar`; defaults to the same as `sidebar`             |
| `width`                | int    | `700`       | Control Center width in pixels (`600`–`1200`). This is the full-sidebar width; the compact and no-sidebar modes scale down from it.                                                                           |
| `show_shortcut_labels` | bool   | `true`      | Show text labels under Home shortcut icons. When `false`, shortcuts are icon-only and glyphs scale with cell size.                                                                                            |
| `show_session_button`  | bool   | `true`      | Show the session-actions button in the Home tab header.                                                                                                                                                       |
| `show_avatar_border`   | bool   | `true`      | Show the accent ring around the Home tab avatar. When `false`, the avatar has no ring, including on hover and keyboard focus.                                                                                 |
| `hidden_tabs`          | array  | `[]`        | Tab [context IDs](#sidebar-tabs) to hide, for example `["monitor", "weather"]`. Empty shows every available tab. The Home tab cannot be hidden.                                                               |

Keyboard navigation uses the global [`[keybinds]`](/noctalia/configuration/keybinds/) actions:

- `tab_next` / `tab_previous` switch between the sidebar and the active tab body.
- `category_next` / `category_previous` move between tabs, wrapping at the ends.
- Arrow keys move within the focused pane.
- In the notifications tab, `delete` removes the topmost notification.

### Sidebar Tabs

Use these context IDs with `noctalia msg panel-toggle control-center <context>` or `noctalia msg panel-open control-center <context>` to open a specific tab.

| Context         | Tab           | What it shows                                                                                                 |
| --------------- | ------------- | ------------------------------------------------------------------------------------------------------------- |
| `home`          | Home          | User card, media summary, date/time, weather summary, and shortcut buttons                                    |
| `media`         | Media         | MPRIS players, playback controls, queue-style player switching, and artwork                                   |
| `audio`         | Audio         | Output/input volume, mute controls, devices, streams, and media-related audio controls                        |
| `monitor`       | Monitor       | Brightness controls for displays that expose writable backlight devices                                       |
| `system`        | System        | Distro/kernel, hardware summary, uptime, CPU/RAM/GPU/network graphs, and resource details                     |
| `network`       | Network       | Wi-Fi state, connection status, cellular controls, known wireless controls, and NetworkManager-backed actions |
| `bluetooth`     | Bluetooth     | Adapter power, discoverability, paired devices, connection controls, and pairing flows                        |
| `weather`       | Weather       | Current conditions, forecast, location status, and weather service diagnostics                                |
| `calendar`      | Calendar      | Month view and configured calendar account events                                                             |
| `notifications` | Notifications | Notification history, Do Not Disturb, and notification cleanup controls                                       |
| `screen-time`   | Screen Time   | Foreground app usage totals and charts for today, three days, or fourteen days                                |
| `power`         | Power         | Battery charge and status, power profiles, battery health, and connected-device battery levels                |

- `weather`, `system`, and `screen-time` open only when their services are enabled. `power` opens only when UPower or `power-profiles-daemon` is available. Otherwise Noctalia falls back to the first visible tab.
- Tabs listed in [`hidden_tabs`](#sidebar) drop from the sidebar, keyboard navigation, and the launcher's [Panels provider](/noctalia/launcher/#panels).
- Every other tab except Home gets its own row in the [Panels provider](/noctalia/launcher/#panels) (`/pan`), so you can jump straight to, say, Bluetooth. Home stays available through the main Control Center row.

## Home

The Home tab is the default landing view. It combines frequently checked status with a compact shortcut grid, configured separately under [Control Center shortcuts](/noctalia/control-center/shortcuts/).

- **User card:** prefers a landscape wallpaper from the connected monitors, else the first available image.
- **Avatar:** click it to pick a custom image, saved as `[shell].avatar_path`.
- **Circular avatar:** on by default. Disable **Circular Avatar** under **Settings → Shell → General**, or set `[shell].circular_avatar = false`, to use the shell's corner roundness in Control Center and the launcher. A roundness of zero gives square corners.
- **Avatar border:** disable **Show Avatar Border** under **Settings → Control Center → Home**, or set `[control_center].show_avatar_border = false`, to remove the accent ring, including on hover and focus.
- **Date/time card:** click it to open the Weather tab. With `[weather].enabled = false`, the card hides its weather line and opens the Calendar tab instead.
- **Session button:** `show_session_button = false` hides it from the header. Home shortcuts with `type = "session"` and bar session widgets are not affected.

:::note
With AccountsService available, Noctalia also writes the avatar to `org.freedesktop.Accounts` as your user's `IconFile`, which Noctalia Greeter shows in its user list. If your distro doesn't enable it, install and enable **accountsservice** (usually the `accounts-daemon` service) to share the avatar with the greeter.
:::

## Media

The Media tab shows active MPRIS players with playback controls, independent of any bar media widget. It helps when several players run or artwork needs more room than a bar capsule.

```toml
# Show the audio visualizer
[control_center.media]
show_visualizer = true
```

| Option            | Type | Default | Description                                                                                                                 |
| ----------------- | ---- | ------- | --------------------------------------------------------------------------------------------------------------------------- |
| `show_visualizer` | bool | `true`  | Show the PipeWire audio visualizer beside the playback controls. Also toggled from the visualizer button in the tab header. |

## Audio

The Audio tab groups PipeWire output, input, device, and stream controls. Use it to change volume, mute, select devices, and inspect application streams without an external mixer.

## Monitor

The Monitor tab shows brightness controls when Noctalia has a writable backlight for the display. Without one, the tab stays available but has no controls.

## System

The System tab summarizes the machine and live resource use:

- distribution and kernel, board, CPU and GPU information
- uptime, install age, and load averages
- memory and swap, plus graphs from the shared system monitor service

Sampling is configured under `[system.monitor]`; see [System monitor](/noctalia/services/system-monitor/).

## Network

The Network tab shows wireless state and connection details from the network backend. It is the destination for Wi-Fi shortcuts and network right-click actions.

**Backend choice:**

- NetworkManager is preferred and followed on the system bus. If it starts or restarts after the shell, the tab picks it up; while it is stopped, the network shows as unavailable.
- If NetworkManager's systemd unit is enabled, it stays the backend even when not yet running at startup.
- Otherwise a standalone wpa_supplicant or iwd backend is used if one is running at startup and lists its interfaces. With neither, the tab waits for NetworkManager.

**Connection line:** shows the IPv4 address, signal strength, radio band, and external IP. The band (`2.4 GHz`, `5 GHz`, `6 GHz`, or `60 GHz`) appears only when the backend reports the frequency: NetworkManager and wpa_supplicant do, iwd does when Station diagnostics give a positive frequency.

**Password prompts:**

- Clicking a secured network you haven't joined, or a backend password request, shows a prompt above the network list with its first field focused.
- A NetworkManager request opens the Control Center on the Network tab if it is closed or on another tab.
- Closing the Control Center leaves the prompt waiting, so you can look up a password or code and come back. NetworkManager gives up after two minutes.
- The eye button shows the password as plain text; copy and cut stay blocked while it is visible.

**VPN secrets (NetworkManager):**

- VPNs that need secrets get the same prompt, filled with the fields the VPN plugin asks for (such as a password, then a one-time code on challenge) and the plugin's message.
- Plugins whose auth helper can't describe its fields, such as OpenConnect, open their own window instead.
- Secrets stored "for this user only" are saved to your keyring (Secret Service, e.g. GNOME Keyring or KWallet) and reused without asking. Noctalia prompts again only when NetworkManager rejects the saved one.
- These are the same keyring entries `nm-applet` and GNOME Shell use, so their saved secrets carry over. Secrets set to "ask for this password every time", such as one-time codes, are never saved.

**Failures (NetworkManager):** a failed Wi-Fi connection shows a notification naming the network and the reason: rejected or missing password, out of range, no response, no IP address, or not authorized. Cancelling or switching networks does not notify. An authorization failure usually means no polkit agent answered; see [the FAQ](/noctalia/getting-started/faq/#networkmanager-polkit).

**Hotspot:** while NetworkManager runs a Wi-Fi device as an access point, the tab doesn't list the hotspot as joined or scan on that device. The Wi-Fi list says the device runs a hotspot, and the Wi-Fi shortcut shows a hotspot icon. Turning Wi-Fi off stops the hotspot.

### Enterprise Wi-Fi (802.1X)

Clicking a WPA2/WPA3-Enterprise network opens a credential form instead of the pre-shared-key field. The password field below the form is used for the EAP login.

| Field                | Notes                                                                       |
| -------------------- | --------------------------------------------------------------------------- |
| EAP method           | PEAP or TTLS                                                                |
| Inner authentication | PEAP: MSCHAPv2 only (dropdown pinned). TTLS: PAP, MSCHAP, MSCHAPv2, or CHAP |
| Identity             | Your login name                                                             |
| Anonymous identity   | Outer identity, if your organization uses one                               |
| Server domain suffix | Optional RADIUS server name suffix your organization publishes              |
| CA certificate path  | Empty trusts the system CA store; an absolute path pins that file instead   |

:::caution
Enterprise networks are recognized on the NetworkManager backend only; wpa_supplicant and iwd show a pre-shared-key prompt an 802.1X network cannot accept. Certificate-based EAP-TLS, including WPA3-Enterprise 192-bit, is not supported; the form says so. Use `nmcli` or another NetworkManager front end for those.
:::

### Cellular

When ModemManager reports a modem, the Network tab adds a **Cellular** card. It has a mobile-data switch and one row per modem with its operator (or hardware name), state, access technology (`5G`, `LTE`, `HSPA+`, ...), and signal percentage.

- The card disappears when ModemManager stops or the modem is unplugged.
- With a saved NetworkManager `gsm` profile, the switch turns the data connection on and off and keeps the modem registered. Without one, it powers the modem radio.
- Turning it on can take several seconds; the switch holds the requested position until the change lands.
- Requires ModemManager (`org.freedesktop.ModemManager1`) and, for mobile data, a `gsm` profile made with `nmcli` or another NetworkManager front end. Noctalia does not create or edit cellular profiles.

## Bluetooth

The Bluetooth tab shows adapter power, paired devices, and connection controls, backed by Noctalia's Bluetooth service and agent.

- Devices paired from the tab are marked trusted, which turns on **Auto-reconnect**.
- Service access prompts name the service (for example, Audio Sink or Hands-Free) instead of a raw UUID.
- **Accept** allows that one request. **Trust and allow** also trusts the device, so BlueZ grants future requests without prompting and **Auto-reconnect** turns on. Turn off **Auto-reconnect** to revoke that trust.
- **Auto-reconnect** only sets BlueZ trust. Whether Noctalia connects trusted devices at startup or notifies about connection changes is set under [Bluetooth](/noctalia/services/bluetooth/).

## Weather

The Weather tab expands the Home weather summary into current conditions, forecast detail, and location status. It is hidden when `[weather].enabled = false`. See [Weather](/noctalia/services/weather/) for configuration.

## Calendar

The Calendar tab shows the month view and events from configured accounts, set up under [Calendar](/noctalia/services/calendar/). Right-click a day to launch the app registered for the `text/calendar` MIME type; the panel closes after a successful launch.

`[control_center.calendar]` controls how the tab is drawn. `[calendar]` controls event sync and the shared `event_date_format` and `event_time_format`, documented under [Calendar](/noctalia/services/calendar/).

```toml
# Calendar tab defaults
[control_center.calendar]
show_events_card = true
show_week_numbers = false
show_events_location = false
hide_past_events = false
past_events_threshold_minutes = 30
```

| Option                          | Type | Default | Description                                                                                                                                                                                                            |
| ------------------------------- | ---- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `show_events_card`              | bool | `true`  | Show the event list beside the month grid. Also toggled from the calendar button in the tab header.                                                                                                                    |
| `show_week_numbers`             | bool | `false` | Show ISO 8601 week numbers left of the month grid, numbered by the week each row's Thursday falls in. Works with `[calendar].enabled = false` and no accounts.                                                         |
| `show_events_location`          | bool | `false` | Show each event's location below its time. Web links (`http://` or `https://`) are not shown. The desktop calendar widget has its own `show_events_location` setting.                                                  |
| `hide_past_events`              | bool | `false` | Hide today's finished events from the list (other days unaffected); when `false` they are dimmed. A **Show N past events** row reveals them; click again to hide. The desktop calendar widget follows this option too. |
| `past_events_threshold_minutes` | int  | `30`    | With `hide_past_events` on, an event stays visible this many minutes after it ends (0–1440). `0` hides it as soon as it ends.                                                                                          |

## Notifications

The Notifications tab shows notification history and actions, including Do Not Disturb. Daemon and history behavior are under [Notifications](/noctalia/services/notifications/).

## Screen Time

The Screen Time tab shows how long each application was in the foreground. Noctalia tracks the active `zwlr_foreign_toplevel` window, pauses while the session is locked, and stores daily totals in `$XDG_STATE_HOME/noctalia/screen_time.json` (about 14 days kept).

- **Range** toggle: today (hourly chart), last 3 days, or last 14 days (daily bars)
- **Total** time for the selected range, with a stacked bar chart (hourly or per-day)
- **Chart legend** as a horizontal row under the chart (chart colors only; app list uses neutral bars)
- **Most used** apps with icons, usage bars, and duration for the selected range

Open it from the sidebar (`screen-time` context) or a Home shortcut with `type = "screen_time"`. Reset history from **Settings → System → Screen Time → Reset Screen Time Data**, which clears `screen_time.json` while Noctalia runs.

## Power

The Power tab consolidates battery and power-management status, backed by UPower and `power-profiles-daemon`:

- **Battery** - charge percentage, charging/discharging state, time remaining (or time until full), and current draw in watts
- **Power Profile** - a selector for the profiles your machine exposes (power-saver, balanced, performance); same as the Home shortcut and bar widget
- **Battery Health** - current full-charge capacity as a percentage of the original design capacity
- **Connected Devices** - battery levels for peripherals such as Bluetooth mice, keyboards, and headsets

Each section appears only with its data: battery and health need a system battery, the profile selector needs `power-profiles-daemon`, and connected devices appear when peripherals report a battery. The tab is hidden when neither UPower nor `power-profiles-daemon` runs.
