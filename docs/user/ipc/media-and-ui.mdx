These commands control user-facing shell features that are not tied to one persistent surface.

## Notifications

| Action                     | Command                                              | Description                                                                                                                     |
| -------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Enable Do Not Disturb      | <IpcCommand command="notification-dnd-set on" />     | Hide current notification toasts and suppress new ones. Notification history still fills.                                       |
| Disable Do Not Disturb     | <IpcCommand command="notification-dnd-set off" />    | Allow new notification toasts; hidden or suppressed toasts are not replayed.                                                    |
| Toggle Do Not Disturb      | <IpcCommand command="notification-dnd-toggle" />     | Toggle notification toast suppression. Notification history still fills.                                                        |
| Show Do Not Disturb status | <IpcCommand command="notification-dnd-status" />     | Print the current Do Not Disturb state.                                                                                         |
| Send internal notification | <IpcCommand command="notification-show <summary>" /> | Create a Noctalia-origin notification with the provided summary text.                                                           |
| Invoke latest notification | <IpcCommand command="notification-invoke-latest" />  | Invoke the default action of the most recent active notification (raises/focuses the source app), mirroring a toast left-click. |
| Clear active notifications | <IpcCommand command="notification-clear-active" />   | Dismiss all currently visible active notifications. Dismissed notifications stay in control-center history.                     |
| Clear notification history | <IpcCommand command="notification-clear-history" />  | Remove all entries from notification history.                                                                                   |

DND enable/disable IPC commands show a short OSD for the new state.

`notification-show` accepts a summary, and CLI usage can pass body as a second argument:

```sh
noctalia msg notification-show "Build finished"
noctalia msg notification-show "Build finished" "All tests passed"
```

When a body argument is passed, the CLI forwards it as structured payload (`summary` + `body`) to the IPC handler.

For full control, pass a JSON payload object:

```sh
noctalia msg notification-show '{"app_name":"Noctalia","summary":"Build finished","body":"All tests passed","urgency":"low","timeout_ms":4000,"icon":"circle-check"}'
```

Supported JSON fields:

- `app_name` (string): application label shown for the notification (default `Noctalia`)
- `summary` (string, required for JSON mode): notification title text
- `body` (string): body text
- `urgency` (string): one of `low`, `normal`, `critical`
- `timeout_ms` (integer): auto-dismiss timeout in milliseconds (`0` keeps it persistent)
- `icon` (string): icon hint. Plain names are treated as Noctalia glyphs (for example `circle-check`), while paths and URLs are treated as image icons.
- `category` (string): freedesktop category
- `desktop_entry` (string): desktop entry id

## Clipboard

| Action                  | Command                                        | Description                                                                                                                                                                                                                                   |
| ----------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Clear clipboard history | <IpcCommand command="clipboard-clear" />       | Clear clipboard history without opening the panel. Pinned entries survive, so with nothing pinned this clears everything. Does not ask for confirmation. The live selection is untouched; pasting still works until something else is copied. |
| Copy text to clipboard  | <IpcCommand command="clipboard-copy <text>" /> | Set the clipboard selection to `<text>`. Everything after the verb is the payload, so spaces and newlines are kept verbatim. Payloads are capped at 64 KiB by the IPC transport.                                                              |
| Print clipboard text    | <IpcCommand command="clipboard-text" />        | Print the most recent clipboard text on stdout with no trailing newline. Pinned entries and images are skipped, so this matches what pasting into a Noctalia input would insert. Prints nothing when the history holds no text.               |

## Media

| Action                 | Command                                        | Description                                                                                                                                                                                                                                                |
| ---------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Previous track         | <IpcCommand command="media previous" />        | Ask the active MPRIS player to go to the previous item.                                                                                                                                                                                                    |
| Next track             | <IpcCommand command="media next" />            | Ask the active MPRIS player to go to the next item.                                                                                                                                                                                                        |
| Play/pause toggle      | <IpcCommand command="media toggle" />          | Toggle play/pause on the active MPRIS player.                                                                                                                                                                                                              |
| Play                   | <IpcCommand command="media play" />            | Resume playback on the active MPRIS player.                                                                                                                                                                                                                |
| Pause                  | <IpcCommand command="media pause" />           | Pause the active MPRIS player. No-op when nothing is playing.                                                                                                                                                                                              |
| Stop playback          | <IpcCommand command="media stop" />            | Send the MPRIS `Stop` command to the active player and dismiss it: the player is hidden from the media widget until it starts playing again or is explicitly selected with `next-player`/`previous-player`. Use `media pause` to pause without dismissing. |
| Previous player        | <IpcCommand command="media previous-player" /> | Switch the active player to the previous available MPRIS player and pin it.                                                                                                                                                                                |
| Next player            | <IpcCommand command="media next-player" />     | Switch the active player to the next available MPRIS player and pin it.                                                                                                                                                                                    |
| Set player volume      | <IpcCommand command="media volume-set 65" />   | Set the active player's volume. Accepts `65`, `65%`, or a normalized value such as `0.65`.                                                                                                                                                                 |
| Raise player volume    | <IpcCommand command="media volume-up" />       | Raise the active player's volume by the default step (5%).                                                                                                                                                                                                 |
| Raise player by amount | <IpcCommand command="media volume-up 10" />    | Raise the active player's volume by a custom step. Accepts `10`, `10%`, or a normalized value such as `0.1`.                                                                                                                                               |
| Lower player volume    | <IpcCommand command="media volume-down" />     | Lower the active player's volume by the default step (5%).                                                                                                                                                                                                 |
| Lower player by amount | <IpcCommand command="media volume-down 5%" />  | Lower the active player's volume by a custom step.                                                                                                                                                                                                         |

Player volume is clamped to 0–100%. A player already above 100% can be lowered from that level, and raising it will not push it further past its current level. Repeated calls during a held key accumulate instead of re-reading a stale player volume.

## Wallpaper

| Action                           | Command                                                   | Description                                                                                                                                                                       |
| -------------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Random wallpaper now             | <IpcCommand command="wallpaper-random" />                 | Switch to a random wallpaper immediately on all monitors.                                                                                                                         |
| Random wallpaper (one monitor)   | <IpcCommand command="wallpaper-random <connector>" />     | Switch to a random wallpaper on the monitor named by **connector** (e.g. `DP-1`). Other monitors are unchanged. Respects per-monitor directory configuration and theme mode.      |
| Next wallpaper                   | <IpcCommand command="wallpaper-next" />                   | Advance to the next wallpaper in order immediately on all monitors.                                                                                                               |
| Next wallpaper (one monitor)     | <IpcCommand command="wallpaper-next <connector>" />       | Advance to the next wallpaper on the monitor named by **connector** (e.g. `DP-1`). Other monitors are unchanged. Respects per-monitor directory configuration and theme mode.     |
| Previous wallpaper               | <IpcCommand command="wallpaper-previous" />               | Go back to the previous wallpaper in order immediately on all monitors.                                                                                                           |
| Previous wallpaper (one monitor) | <IpcCommand command="wallpaper-previous <connector>" />   | Go back to the previous wallpaper on the monitor named by **connector** (e.g. `DP-1`). Other monitors are unchanged. Respects per-monitor directory configuration and theme mode. |
| Get wallpaper                    | <IpcCommand command="wallpaper-get" />                    | Print the default wallpaper path persisted in `settings.toml`.                                                                                                                    |
| Get wallpaper (one monitor)      | <IpcCommand command="wallpaper-get <connector>" />        | Print the effective wallpaper path for the monitor named by **connector** (e.g. `DP-1`).                                                                                          |
| Set wallpaper (all monitors)     | <IpcCommand command="wallpaper-set <path>" />             | Set every connected monitor and the default wallpaper, persisted to `settings.toml` (per-monitor entries plus `wallpaper.default.path`).                                          |
| Set wallpaper (one monitor)      | <IpcCommand command="wallpaper-set <connector> <path>" /> | Set only the monitor named by **connector** (e.g. `DP-1`). Remaining tokens are joined as the path. Other monitors are unchanged.                                                 |

Wallpaper paths accept an image path (`~` expanded) or `color:#RRGGBB` / `color:#RRGGBBAA`. Non-color paths must exist at call time.

The CLI forwards everything after the command as one string (`noctalia msg wallpaper-set ...`), so `noctalia msg wallpaper-set DP-1 /home/you/My Pictures/wall.jpg` still yields a correct path when the shell passes separate arguments after the command.

## Theme

| Action            | Command                                                    | Description                                                                                                                                |
| ----------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Get theme mode    | <IpcCommand command="theme-mode-get" />                    | Print the current resolved theme mode: `dark` or `light` (from `[theme].mode` or from the `[location]` schedule when mode is `auto`).      |
| Toggle theme mode | <IpcCommand command="theme-mode-toggle" />                 | Switch between dark and light theme mode (same as the bar control when `[theme].mode` is not `auto`).                                      |
| Set theme mode    | <IpcCommand command="theme-mode-set dark" />               | Persist `[theme].mode` in `settings.toml` and reload. Pass `dark`, `light`, or `auto` (example shows `dark`).                              |
| Get color scheme  | <IpcCommand command="color-scheme-get" />                  | Print the active palette selection as two tokens: `builtin Noctalia`, `wallpaper m3-content`, `community Oxocarbon`, or `custom MyScheme`. |
| Set color scheme  | <IpcCommand command="color-scheme-set builtin Noctalia" /> | Persist `[theme].source` and the palette for that source, then reload.                                                                     |
| Apply templates   | <IpcCommand command="templates-apply" />                   | Rerender the enabled configured theme templates for the current palette without changing theme mode or firing shell palette hooks.         |

`color-scheme-set` accepts these source kinds:

- **builtin** - built-in palette name, such as `Noctalia`
- **wallpaper** - generator scheme, such as `m3-tonal-spot`, `m3-content`, `m3-fruit-salad`, `m3-rainbow`, `m3-monochrome`, `vibrant`, `faithful`, `soft`, `dysfunctional`, or `muted`
- **community** - community palette id
- **custom** - palette file name without `.json` under `~/.config/noctalia/palettes/`

## Screenshots

Region and fullscreen capture need compositor support for `wlr-screencopy-unstable-v1`. Window capture uses `ext-image-copy-capture-v1` and `ext-foreign-toplevel-image-capture-source-manager-v1`. Every command follows the [`[shell.screenshot]` output policy](/noctalia/desktop/screenshots/#saving-and-copying) unless [per-call options](#per-call-options) override it; window capture ignores `freeze`.

| Action                       | Command                                               | Description                                                                                                                                                                      |
| ---------------------------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Region screenshot            | <IpcCommand command="screenshot-region" />            | Start interactive region capture (drag to select; press **`[keybinds].cancel`** to dismiss).                                                                                     |
| Fullscreen screenshot        | <IpcCommand command="screenshot-fullscreen" />        | Capture the focused monitor (compositor-selected output, active toplevel, keyboard focus, or recent pointer).                                                                    |
| Fullscreen (pick monitor)    | <IpcCommand command="screenshot-fullscreen pick" />   | Open the display picker on multi-monitor setups. On a single monitor, captures immediately.                                                                                      |
| Fullscreen (specific output) | <IpcCommand command="screenshot-fullscreen DP-2" />   | Capture one output without the picker. Pass the Wayland connector name (e.g. `DP-1`, `HDMI-A-1`) or a word-boundary match in the output description.                             |
| Fullscreen (all monitors)    | <IpcCommand command="screenshot-fullscreen all" />    | One combined desktop image spanning every monitor.                                                                                                                               |
| Window screenshot            | <IpcCommand command="screenshot-window" />            | Capture the focused window at native resolution. Requires `ext-image-copy-capture-v1` and `ext-foreign-toplevel-image-capture-source-manager-v1` support from the compositor.    |
| Annotate a frozen screen     | <IpcCommand command="screenshot-annotate" />          | Freeze every monitor and open the annotation editor over the frozen image. **Copy** and **Save** deliver the annotated image; **`[keybinds].cancel`** closes without delivering. |
| Annotate the live screen     | <IpcCommand command="annotate" />                     | Transparent drawing overlay for presentations. Apps keep updating behind the ink; **`Z`** freezes the screen under it and reveals Blur, Crop, Copy, and Save.                    |
| Annotate an image file       | <IpcCommand command="annotate ~/Pictures/shot.png" /> | Open an image from disk in the editor instead of the screen. No screencopy support needed.                                                                                       |

In picker mode, choose a connector from the top bar on any screen, or click the desktop to capture the monitor under the cursor. Errors list available connector names when the selector is unknown.

### Per-call options

`screenshot-region`, `screenshot-fullscreen`, `screenshot-window`, `screenshot-annotate`, and `annotate` accept options that override single `[shell.screenshot]` keys for one call, so two keybinds for one command can behave differently.

- Each call starts from the config and changes only the named keys.
- Options work from `noctalia msg`, compositor binds, and bar widget actions. `noctalia msg <command> --help` lists them.

| Option                                                             | Values                       | Effect                                  |
| ------------------------------------------------------------------ | ---------------------------- | --------------------------------------- |
| `--save-to-file` / `--no-save-to-file`                             | flag                         | Overrides `save_to_file`.               |
| `--copy-to-clipboard` / `--no-copy-to-clipboard`                   | flag                         | Overrides `copy_to_clipboard`.          |
| `--pipe-to-command` / `--no-pipe-to-command`                       | flag                         | Overrides `pipe_to_command`.            |
| `--freeze-screen` / `--no-freeze-screen`                           | flag                         | Overrides `freeze_screen`.              |
| `--confirm-region` / `--no-confirm-region`                         | flag                         | Overrides `confirm_region`.             |
| `--remember-last-region` / `--no-remember-last-region`             | flag                         | Overrides `remember_last_region`.       |
| `--show-cursor` / `--no-show-cursor`                               | flag                         | Overrides `show_cursor`.                |
| `--annotate` / `--no-annotate`                                     | flag                         | Overrides `annotate`.                   |
| `--skip-annotate-on-copy-save` / `--no-skip-annotate-on-copy-save` | flag                         | Overrides `skip_annotate_on_copy_save`. |
| `--close-on-copy` / `--no-close-on-copy`                           | flag                         | Overrides `close_on_copy`.              |
| `--close-on-save` / `--no-close-on-save`                           | flag                         | Overrides `close_on_save`.              |
| `--copy-on-close` / `--no-copy-on-close`                           | flag                         | Overrides `copy_on_close`.              |
| `--pipe-command <command>`                                         | shell command                | Overrides `pipe_command`.               |
| `--directory <dir>`                                                | path                         | Overrides `directory`.                  |
| `--filename-pattern <pattern>`                                     | pattern                      | Overrides `filename_pattern`.           |
| `--append-mode-suffix` / `--no-append-mode-suffix`                 | flag                         | Overrides `append_mode_suffix`.         |
| `--format <format>`                                                | `png`, `jpeg`, `webp`, `jxl` | Overrides `format`.                     |
| `--quality <1-100>`                                                | whole number 1 to 100        | Overrides `quality`.                    |

- Options go before the fullscreen target or the annotate path; everything after the first non-option word is the target or path.
- Quote values that contain spaces, for example `--pipe-command 'satty -f -'`.
- Combining an option with its `--no-` form is an error, and so is an unknown option, a `--format` outside the listed values, or a `--quality` that is not a whole number from 1 to 100; the command then does nothing.
- `--pipe-command` only sets the command; add `--pipe-to-command` when the config does not already enable piping.
- A relative `--directory` resolves against the directory the command ran in. An empty value selects the default folder, like an empty `directory` key.
- `--format` and `--quality` change only the saved file; the clipboard and the pipe command still receive PNG.
- An option for a key that does not affect the command is accepted and ignored, the same as that key in the config.
- **Capture new region** and **Capture window** in the editor keep the options of the command that opened it.

```sh
# Annotate this region even though annotate = false in the config
noctalia msg screenshot-region --annotate
# Copy straight to the clipboard without the editor and without saving a file
noctalia msg screenshot-region --no-annotate --copy-to-clipboard --no-save-to-file
# Send a combined capture of every monitor to satty
noctalia msg screenshot-fullscreen --pipe-to-command --pipe-command 'satty -f -' all
# Save this region as a lossless WebP file
noctalia msg screenshot-region --format webp --quality 100
```

A Niri bind and a screenshot widget action using the same options:

```kdl
binds {
    Mod+Shift+S { spawn-sh "noctalia msg screenshot-region --annotate"; }
}
```

```toml
[widget.screenshot.actions]
left = "screenshot-region --annotate"
```

### Annotating an image file

`annotate <path>` opens a file in the editor instead of the screen.

- Supports PNG, JPEG, GIF, WebP, JPEG XL, ICO, SVG, and the other wallpaper and icon formats. EXIF orientation is applied.
- The image opens centered at native size on the focused output, scaled down if it does not fit.
- Relative paths resolve against the command's directory, and `~` expands.
- The pointer button is disabled and **Freeze** is not offered.
- **Copy** and **Save** deliver the annotated PNG; **Done** applies the `[shell.screenshot]` output policy.
- Saving never overwrites the source: it writes a new PNG to the screenshot folder using the configured filename pattern.

A hidden desktop entry, `dev.noctalia.Noctalia.Annotator.desktop`, runs `noctalia msg annotate` on a chosen file. File managers list it as **Noctalia Image Annotator** under **Open With** for supported image types. Noctalia must already be running.

### Annotation editor keys

Tool keys (no modifier):

- **`m`** move, **`b`** brush, **`h`** highlighter, **`l`** line, **`a`** arrow, **`s`** rectangle, **`o`** circle, **`t`** text, **`n`** numbering, **`u`** blur, **`e`** eraser, **`c`** crop.
- **`z`** freeze (live overlay), **`p`** toggle the captured pointer, **`f`** cycle shape fill (off, semi-transparent, opaque).
- **`1`** to **`8`** pick the current tool's color from the swatches; **`[`** and **`]`** change its size.

With modifiers:

- **`Ctrl+R`** captures a new region; **`Ctrl+W`** captures the window focused when the editor opened. Both discard the current edit.
- **`Ctrl+Z`** undoes; **`Ctrl+Shift+Z`** and **`Ctrl+Y`** redo.
- **`[keybinds].copy`** (default **Ctrl+C**) copies; **`[keybinds].save`** (default **Ctrl+S**) saves.
- **`Ctrl`** + mousewheel zooms around the pointer (half to sixteen times the fitted size); **`Ctrl`** + left-drag pans.
- **`Ctrl+=`** (or **`Ctrl++`**) zooms in, **`Ctrl+-`** zooms out, **`Ctrl+0`** fits the view.

### Annotation editor behavior

Zoom and pan:

- Zooming never changes the recorded pixels. The toolbar zoom button shows the same controls and the current level.
- Panning keeps part of the capture on screen, and moving the toolbar never reflows the canvas.
- In live annotation only the ink zooms, not the desktop behind it; freeze with **`z`** first to match.

Pointer:

- The pointer button and **P** work the same in region, fullscreen, and frozen-screen editing. `[shell.screenshot].show_cursor` sets the initial choice; toggling does not change it.
- Only the pointer inside the captured area can appear.
- If separate cursor capture (via `ext-image-copy-capture-v1`) is unsupported or fails, the screenshot keeps the configured choice and the button is disabled with a tooltip explaining why.
- In live annotation, freeze with **Z** first.
- Window capture never includes the pointer, so `show_cursor` does not apply and the button stays disabled.

Closing and copying:

- `[shell.screenshot].close_on_copy` and `close_on_save` default to `true`: a successful copy or save closes the editor. Set either to `false` to keep editing. Failures leave the editor open.
- With `[shell.screenshot].copy_on_close = true`, closing (**`[keybinds].cancel`** or the close button) first copies the annotated image.

Capture again (toolbar popover):

- **Capture new region** (**Ctrl+R**) discards the edit, captures a fresh region without the overlay, and reopens the editor with the same pointer choice and tool preferences. Works in live, frozen, and image modes regardless of `[shell.screenshot].annotate`. Cancelling selection closes the capture.
- **Capture window** (**Ctrl+W**) does the same for the window focused when the editor opened, at native resolution. It needs the ext image-capture protocols, never includes the pointer, and reports an error if the window is gone.

Toolbar and canvas:

- Captured images get an inset **Outline** color-role border that is not part of copied or saved images.
- Drag the toolbar's left grab handle to move it. Each output remembers its own position across sessions.
- Every control has a tooltip naming its shortcut.
- The stroke button shows the tool's color with a dot sized to its weight. Its popover has the eight swatches, **S**, **M**, **L** (half, one, or twice the default weight), and a fine `-`/size/`+` stepper whose values are kept.
- The popover closes on the stroke button, **`[keybinds].cancel`**, a canvas press, or opening the backdrop panel. Move and Crop have no stroke button; Eraser and Blur show only size.
- The checked swatch is the live color. Size and color are remembered per tool.
- The shape-fill button cycles **off**, **semi-transparent**, and **opaque** for Rectangle and Circle; right-click cycles in reverse.
- With a text caret open, size and color changes restyle the text under it; any other control commits the text first.

## Color picker

| Action     | Command                             | Description                                                                                 |
| ---------- | ----------------------------------- | ------------------------------------------------------------------------------------------- |
| Pick color | <IpcCommand command="color-pick" /> | Freeze every monitor and pick one pixel; its color is copied to the clipboard as `#RRGGBB`. |

The picker needs `wlr-screencopy-unstable-v1`, like region screenshots.

- The pointer becomes a round loupe that magnifies and outlines the sampled pixel. Its rim and the pill below take the sampled color; the pill shows hex and RGB.
- Scroll to zoom.
- Click, **`[keybinds].validate`**, or **Space** copies the color and shows a notification.
- **`[keybinds].left`**, **`right`**, **`up`**, and **`down`** move one device pixel (**Shift**: ten). Moving the mouse continues from there.
- **`[keybinds].cancel`** closes without copying.
- The command returns once the picker opens, so read the color with `noctalia msg clipboard-text`.
