These commands are useful for media keys, compositor binds, scripts, and custom widgets.

## OSD

| Action | Command | Description |
|--------|---------|-------------|
| Enable all OSD popups | <IpcCommand command="osd-enable" /> | Enable OSD popups for the running shell. |
| Disable all OSD popups | <IpcCommand command="osd-disable" /> | Disable OSD popups and close any visible popup. |
| Toggle all OSD popups | <IpcCommand command="osd-toggle" /> | Toggle OSD popups at runtime and print `on` or `off`. |

`osd-enable`, `osd-disable`, and `osd-toggle` apply only to the running shell and never change the saved `[osd].enabled` setting. Turning OSDs off
immediately closes any visible popup. An explicit change to the saved OSD toggle cancels the runtime override.

## Volume

| Action | Command | Description |
|--------|---------|-------------|
| Set output volume | <IpcCommand command="volume-set 65" /> | Set output volume. Accepts `65`, `65%`, or normalized values such as `0.65`. |
| Raise output volume | <IpcCommand command="volume-up" /> | Raise output volume by the default step. |
| Raise output by amount | <IpcCommand command="volume-up 10" /> | Raise output volume by a custom step. |
| Lower output volume | <IpcCommand command="volume-down" /> | Lower output volume by the default step. |
| Mute output | <IpcCommand command="volume-mute" /> | Toggle output mute. |
| Show volume OSD | <IpcCommand command="volume-osd" /> | Show the volume OSD at the current volume without changing it. |
| Show volume OSD at value | <IpcCommand command="volume-osd 72" /> | Show the volume OSD at the given value without changing volume. |

Default step is 5% when not specified. Output volume is clamped to 100% unless `[audio] enable_overdrive = true`, which allows up to 150%. The same ceiling applies to the value accepted by `volume-osd`.

## Microphone

| Action | Command | Description |
|--------|---------|-------------|
| Set mic volume | <IpcCommand command="mic-volume-set 0.5" /> | Set microphone volume. Accepts normalized or percent values. |
| Raise mic volume | <IpcCommand command="mic-volume-up" /> | Raise microphone volume by the default step. |
| Raise mic by amount | <IpcCommand command="mic-volume-up 5%" /> | Raise microphone volume by a custom step. |
| Lower mic volume | <IpcCommand command="mic-volume-down" /> | Lower microphone volume by the default step. |
| Mute mic | <IpcCommand command="mic-mute" /> | Toggle microphone mute. |
| Show mic OSD | <IpcCommand command="mic-volume-osd" /> | Show the microphone OSD at the current volume without changing it. |
| Show mic OSD at value | <IpcCommand command="mic-volume-osd 40%" /> | Show the microphone OSD at the given value without changing volume. |

`volume-osd` and `mic-volume-osd` never change the level. Called with no value they show the current one, which suits a "show me the volume" bind. Called with a value they show that value instead, for scripts that manage volume outside Noctalia such as an MPD volume sync. Both appear on whichever monitors are configured under `[osd].monitors`, and both reflect the real mute state of the device.

## Brightness

| Action | Command | Description |
|--------|---------|-------------|
| Set current brightness | <IpcCommand command="brightness-set 65" /> | Set brightness on the current monitor. |
| Set one monitor | <IpcCommand command="brightness-set DP-1 0.65" /> | Set brightness for a specific monitor or monitor selector. |
| Set all monitors | <IpcCommand command="brightness-set * 40%" /> | Set brightness on every monitor. |
| Raise current brightness | <IpcCommand command="brightness-up" /> | Raise brightness by the default step. |
| Raise one monitor | <IpcCommand command="brightness-up DP-1 10" /> | Raise brightness for one monitor. |
| Lower all monitors | <IpcCommand command="brightness-down * 5%" /> | Lower brightness on every monitor. |
| Show brightness OSD | <IpcCommand command="brightness-osd 72" /> | Show the brightness OSD at the given value without changing brightness. Useful when an external script controls brightness. |

Targets can be `current`, `all`, `*`, a monitor connector name such as `eDP-1` or `DP-1`, or a monitor selector token. Values accept normalized `0.0` to `1.0` or percentage form such as `65`, `65%`, and `5%`.

`brightness-osd` takes a value only - unlike `brightness-set`, it has no monitor target. The OSD appears on whichever monitors are configured under `[osd].monitors`.

## Power profile

Requires `org.freedesktop.UPower.PowerProfiles` (same as the Control Center home shortcut). Profile ids come from the compositor/session; common values are `performance`, `balanced`, and `power-saver`.

When another app or an IPC command changes the active profile, Noctalia shows a short OSD with the active mode's icon and profile name. Profile changes made through Noctalia's UI update the UI and fire hooks without showing extra OSD feedback.

| Action | Command | Description |
|--------|---------|-------------|
| Set power profile | <IpcCommand command="power-set balanced" /> | Activate the named profile. If the service reports a profile list, the name must match one of those entries exactly. |
| Cycle power profile | <IpcCommand command="power-cycle" /> | Switch to the next profile in UPower's ordered list (same order as the bar power widget and control center shortcut). Wraps from the last profile back to the first. Takes no arguments. |
